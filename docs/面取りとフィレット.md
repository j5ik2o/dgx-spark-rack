# 印刷部品の面取りとフィレット

大きな部品の外周はC0.3、小部品はC0.2、ファン送風開口の前縁はR0.3を基準にします。Cは45度の面取り寸法、Rは丸みの半径で、単位はmmです。形状の正本へ加工を反映し、スライサー上の表示だけでは処理しません。

| 部品 | 処理 |
|---|---|
| 本体ラック・アダプターラックの左右側枠 | 外側の広い面にある直線の凸稜線をC0.3。内側の差込面を一括加工しない |
| 両ラックの支持棒・短い棒の試験片 | 側面・上下の外周凸稜線をC0.3 |
| 両ラックのファン保持板 | 前後の外周凸稜線をC0.3、前側の送風開口をR0.3 |
| 横連結クリップ・上下保持板・横連結ブリッジ | 外周凸稜線をC0.3。アダプターラックのブリッジ突起先端はC0.2 |
| 固定ピン・上下位置決めピン | 両端をC0.2。軸径と中央の接触部は保持 |
| 接合試験片 | 対応する側枠と同じ外側の広い面のみC0.3。差込口の加工条件を変えない |
| 金具試験片 | 外周をC0.3。測定対象の円形穴・六角穴の縁は保持 |
| 共通ドック | 外形R4、外周上下の稜線R0.4、通風窓の角R4、ケース側の直線の凸稜線C0.3 |
| ファンコンケース本体 | 既存の外周R3、上下端R0.4、配線開口の外縁R0.3を維持 |
| ケースの取付耳 | 先端R3、上面外周R0.3。M3の90度皿座は保持 |
| 蓋 | 既存の外周R3・天面の縁R0.4を維持 |
| 独立した基板押さえ | 上面の外周凸稜線C0.2。下面の着座面とねじ穴は保持 |

全稜線へ無条件に加工することはしません。既に丸まった面、凹稜線、円形の取付穴・ねじ座・差込面などは除外し、部品ごとに指定した面から対象を選びます。ピンの先端など、機能上意図した入口処理は別に指定します。

共通処理は [edge_finishing.py](../tools/cad/edge_finishing.py) です。アダプターラックでは寸法変更に伴う稜線番号の変化を避けるため、加工前フィーチャーと対象面を保持するPythonフィーチャーで再計算します。再計算にはこのモジュールが読み込まれている環境が必要です。通常どおり生成マクロを使ってください。保存済みの形状だけを編集して正本とはしません。

検査では有効な単一ソリッド、組立干渉、差込口の向き、上下接触面、寸法変更・復元、FCStd再読込、STLの閉じた形状を確認します。面取り後は上下の平面面積が変わるため、差込口が上を向くことは空洞内部と背面の検査点で判定します。手触り・実物の適合・強度は試作で確認してください。
