# CADと3MFをコマンドで生成する

`mise`、FreeCAD、Bambu Studioを使います。macOSの `/Applications` にインストールした環境で動作確認しています。初回はリポジトリのルートで `mise trust`、続けて `mise run doctor` を実行します。

## 使うコマンド

| コマンド | 出力 |
|---|---|
| `mise run build` | 全3モデルのFCStd・STEP・STL・検査結果・manifest。ラックは配置画像も生成 |
| `mise run build:spark-rack` | 本体ラックだけを生成・検査 |
| `mise run build:adapter-rack` | アダプターラックだけを生成・検査 |
| `mise run build:fan-controller` | ケースだけを生成・検査 |
| `mise run 3mf` | 全3モデルをCADから再生成し、部品別の3MFを作成 |
| `mise run 3mf:spark-rack` | 本体ラックのCADと3MFを生成 |
| `mise run 3mf:adapter-rack` | アダプターラックのCADと3MFを生成 |
| `mise run 3mf:fan-controller` | ケースのCADと3MFを生成 |
| `mise run test` | タスクの入力検査・失敗時の扱いを検査 |

**`3mf` はCAD生成を含みます。先に `build` を実行する必要はありません。** 全モデルのタスクは順番に実行します。FreeCADのGUIが起動しますが、通常終了後に閉じます。途中で失敗した場合はタスクもエラーで終了します。

生成先は次の2か所です。毎回新しい実行IDを使い、既存ファイルは上書きしません。

- CAD：`build/<モデル名>/<実行ID>/`
- 3MF：`print-projects/<モデル名>/generated/<実行ID>/`

どちらも自動生成フォルダはGit管理対象外です。3MF側のmanifestに、元のCAD実行ID・STLハッシュ・プロファイルのハッシュ・検査結果を保存します。既存の手調整済み3MFはそのまま保全します。生成後に調整して採用した3MFは、`generated/` の外のモデル別フォルダへ別名保存してください。

## 部品と個数を指定する

既定は**試験片を含む全種類を、1種類につき1個ずつ別の3MF**にします。組立1台分の部品数ではありません。必要な数は各モデルの部品表で確認してください。ピンと大型部品は別ファイルになります。

```sh
# ケースの蓋を2個。CADは先に自動生成する
mise run 3mf:fan-controller -- --part CaseLid --copies 2

# 既に生成・検査したSTLを使う（日時部分は実際の出力先に置き換える）
mise run 3mf:spark-rack -- --build-dir build/spark-rack/実行ID --part locking_pin --copies 6
```

`--build-dir` は指定モデルの成功した出力だけを受け付けます。設計コードや生成物のハッシュが変わっていれば停止するので、再生成してください。失敗した実行のmanifestは `failed` になります。

## 3MFの印刷設定

共通の[PLA試作用プロファイル](../print-projects/profiles/pla-prototype.json)を使います。プリンターはX1 Carbon・0.4mmノズル、材料はBambu PLA Basic、プレートはTextured PEI、積層0.20mm、壁4周、インフィル20%、外側ブリム5mmです。Bambu Studioに同梱された設定を継承するため、アプリ更新で既定値が変わることがあります。生成した3MFに実際の設定が保存されます。

これは**スライス前のプロジェクト3MF**です。G-code生成・プリンター送信は行いません。Bambu Studioで開いて、必要なサポート・向き・プレート配置・個数・実際のフィラメント割り当てを確認してからスライスしてください。本番素材への変更は別途必要です。CLIの自動配列は使いますが、自動回転は無効にしてCADで設定した造形方向を保持します。

3MF生成にはBambu Studio公式の `--load-settings`、`--load-filaments`、`--export-3mf` を使っています。[公式CLI説明](https://github.com/bambulab/BambuStudio/wiki/Command-Line-Usage)

## インストール先が異なる場合

次の環境変数で変更できます。互換性のあるFreeCADのPython・ライブラリを組にして指定してください。GUIを利用するため、ディスプレイのない環境では追加の対応が必要です。

| 変数 | 既定値 |
|---|---|
| `FREECAD_PYTHON` | `/Applications/FreeCAD.app/Contents/Resources/bin/python` |
| `FREECAD_LIB` | `/Applications/FreeCAD.app/Contents/Resources/lib` |
| `BAMBU_STUDIO` | `/Applications/BambuStudio.app/Contents/MacOS/BambuStudio` |
| `BAMBU_PROFILES` | `/Applications/BambuStudio.app/Contents/Resources/profiles/BBL` |

`mise`を使わない場合も `python3 tools/tasks/cad.py build spark-rack` や `python3 tools/tasks/cad.py 3mf fan-controller` で同じ処理を実行できます。
