# Fusion版：パラメーターからラックを編集する

[DGX-SPARK-RACK-FUSION-v1.f3d](../DGX-SPARK-RACK-FUSION-v1.f3d)が設計の唯一の正本です。スケッチ、押し出し、フィレット、ジョイントをFusion内に保持しています。STEP・STL・画像は派生データとして扱います。

まずF3Dを開き、下のパラメーター表を参照してください。変更後は「MCPから検査・書き出しする」を使います。印刷・組立の流れは[試作ガイド](試作ガイド.md)と共通です。

## 幅・高さ・接合隙間を変更する

Fusionで「パラメータを変更」を開きます。主に編集する値は次のとおりです。

| 名前 | 初期値 | 変更対象 |
|---|---:|---|
| ModuleWidth | 210 mm | 1ユニットのフレーム幅 |
| ModuleDepth | 230 mm | フレームの奥行 |
| FrameHeight | 170 mm | 側板の高さ |
| FitClearance | 0.3 mm | 差込部とピン穴の片側の隙間 |
| SupportTop | 60 mm | 本体を支える棒の上面高さ |
| ColumnGap | 10 mm | 左右のユニット間隔 |
| StackGap | 4 mm | 上下のユニット間隔 |
| FanHolePitch | 124.5 mm | ファンの取付穴ピッチ |

`InnerX`、`PinX`、`ColumnPitch`などは、主寸法から計算する値です。関連する部品の位置がそろうよう、通常はこれらの式を維持してください。寸法を大きく変えたり、異なるファン規格へ変更したりする場合は、部品のつながりと干渉を再確認します。

検証では`ModuleWidth`を210→214 mmに変更し、支持棒の長さが204→208 mm、4台配置の全幅が434→442 mmへ連動することを確認しました。その後、初期値に戻しています。パラメーターは計33個で、派生する寸法式も含みます。

## ファイルを用途に合わせて選ぶ

| ファイル | 用途 |
|---|---|
| [F3D](../DGX-SPARK-RACK-FUSION-v1.f3d) | Fusionで設計履歴とパラメーターを編集 |
| [STEP](../exports/fusion/DGX-SPARK-RACK-FUSION-v1.step) | 4台の組立形状を他のCADへ渡す |
| [STL](../exports/fusion/stl) | Bambu Studioへ読み込む印刷部品12種類。単位はmm |
| [4台プレビュー](../exports/fusion/four_units.png) | 全体の外観を確認 |
| [1台プレビュー](../exports/fusion/single.png) | 単体の形状を確認 |
| [縦2台](../exports/fusion/two_vertical.png)／[横2台](../exports/fusion/two_horizontal.png) | 初期配置を比較 |

F3D内の「部品原型_通常は非表示」は、共通部品の定義です。「ラック_組立」に実際の配置をまとめています。本体、ファン、ガード、ねじ、ナットは`REF_`で始まる参照部品です。これらは印刷用STLから除外しています。

外観色は部品を見分けるためのものです。ASAの物性値を設定して強度や熱を解析したモデルではありません。

## MCPから検査・書き出しする

Fusionを起動し、基本設定の「一般 → API」で組み込みMCPサーバーを有効にします。通常の接続先はローカルポート27182です。このリポジトリのHTTPクライアントから実行します。

F3Dの正本をFusionで開き、編集した文書をアクティブにして次を実行します。

```sh
python3 scripts/fusion_rack_cli.py validate
python3 scripts/fusion_rack_cli.py export
```

寸法の管理元はF3D内のパラメーターです。初期生成用JSONとモデルを再構築するコマンドは削除しました。`export`は、現在の検査済みモデルからF3D・STEP・STLを書き出します。

書き出しでは、検査したモデルと現在の寸法式・形状が一致することを確認します。ほかの文書がアクティブな場合は、識別用の属性を確認して処理を停止します。

接続確認は次のコマンドです。独自のポートを使っている場合は、`--url`で接続先を指定してください。

```sh
python3 scripts/fusion_mcp.py list
```

## 確認済みの範囲と、これから試す範囲

設計データの検査では、印刷部品の全スケッチが完全拘束で、部品が閉じたソリッドであることを確認しました。80個のボディを対象とした干渉検査では、0.001 mm³を超える食い込みはありませんでした。ファン内部とガードの簡略参照形状は、この干渉検査から除外しています。

F3Dの書き出し後に開き直し、33個のパラメーター、440項目の設計履歴、形状の特徴量が保持されることも確認しています。STLは別のプログラムで読み、閉じた形状、接続成分、正の体積、造形寸法を検査しました。最大寸法は210mmです。

記録は[CAD検査](../exports/fusion/validation.json)、[F3D再読込](../exports/fusion/roundtrip.json)、[STL検査](../exports/fusion/stl_validation.json)にあります。

**実機の足・通風口・コネクターとの適合、長期荷重、冷却性能は未検証です。** 接合用の試験片から始めてください。実機を置く前に、支持位置とケーブルを挿した状態を確認します。

寸法変更で意図しない形になった場合は、変更したパラメーター、検査結果、対象部品名をこの作業の会話に伝えてください。BRepはCAD内部のソリッド表現、ジョイントは部品間の位置関係、完全拘束はスケッチの位置と形が寸法・拘束で決まった状態を指します。
