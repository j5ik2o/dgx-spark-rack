# 連結式ラックの設計を2026年10月9日時点で保全

4台専用ラックへの再設計前のデータを、[dgx-spark-modular-rack-repository-20261009.zip](dgx-spark-modular-rack-repository-20261009.zip)に保存しました。本体ラック、電源アダプターラック、ファンコントローラーケースの設計コード、説明、印刷設定、共通ツール、過去のアーカイブを含みます。展開すると当時のリポジトリ構成に戻ります。

保存時のファイル一覧、内容を照合するSHA-256ハッシュ、元のコミットは[preservation-manifest.json](preservation-manifest.json)、圧縮ファイルの検査と全ファイルの一致確認は[preservation-validation.json](preservation-validation.json)に記録しました。人間専用の`AGENTS.md`は複製対象から外しています。このworktreeには`build/`の生成履歴がありません。別worktreeやFreeCADの未保存文書は、この保全には含みません。

## 旧版と新設計を区別する

保存パッケージの名前は「対象・連結式・保全日」でそろえました。作業側の本体ラック用印刷設定にも`modular-spark-rack-`を付け、4台専用の新設計用と区別しています。名前の対応はmanifestの`renamed_working_files`にあります。圧縮ファイル内には変更前の名前と内容を保持しています。

Pythonと実行マクロの名前は、読み込み関係を保つため変更していません。作業側の`models/`と生成タスクにも従来の実装を残しています。現在の本体ラック生成タスクは連結式ラックを作ります。新しい4台専用ラックには[仮配置の検討モデル](../../models/spark-rack/docs/仮配置の確認.md)を用意し、印刷部品はまだ実装していません。

## 取り出すときは別フォルダへ展開する

圧縮ファイルは空の作業フォルダへ展開してください。現在の`models/`へ展開すると新設計を上書きするおそれがあります。当時の説明や検査記録は、保存時のパスを記録したものです。

旧版を再生成する場合は、出力をリポジトリの`archive/build-history/`内の新しい実行フォルダへ指定します。保存済みの設計ファイルや印刷設定に上書きしません。再生成にはFreeCADなど、当時の生成手順に記載した環境が必要です。

次の設計条件は[4台専用ラックの設計条件](../../models/spark-rack/docs/4台専用ラックの設計条件.md)に記録しています。
