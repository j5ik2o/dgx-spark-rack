# スイッチを受け梁で支え、板ごと後ろへ交換する

2026年10月10日のユーザー指定により、支持部を全体から外さず設計します。CRS804とCRS812の仮外形を使い、受け板、梁、柱の受け穴、固定具、交換経路まで参照CADへ組み込みました。実寸が未確認のため、製造用データと耐荷重の保証には進みません。試験片の印刷も後回しのままです。

## 荷重を板、横梁、奥行梁、柱へ伝える

第一候補は452×423×3mmのアルミ受け板です。幅456mmの柱間を通るよう左右各2mmの隙間を設けました。受け板の裏面高さは182.25mm、上面は185.25mm。参考の底面脚を2mmとし、スイッチ筐体の底面を187.25mmへ置きます。脚の高さと位置は実測値ではありません。

受け板を支える横梁は前後2本です。その根元に段差を付け、左右の奥行梁の受け面へ載せます。奥の突起は位置を決め、受け穴の底から2mm浮かせます。奥行梁も四隅の柱の段差で受けます。別部品の外板を継ぎ手として追加しません。

| 支持部 | 仮設計の寸法・位置 |
|---|---|
| 奥行梁 | 28mm角。内のり464mmを180・142・142mmへ分割し、端の二股でつなぐ |
| 横梁 | 幅28×高さ20mm。前側の中心は−322mm、後ろ側は16mm。左右に分割し、中央を二股でつなぐ |
| 柱の分割 | 支持段の182.25mmで上下を分ける。下側に12×6×高さ24mmの位置決め突起を付け、上側に受け穴を設ける |
| 受け板 | 452×423×3mm。前端−395mm、後端28mm。スイッチ取付耳を外す条件 |

柱の下側は突起込みで206.25mm、上側は237.75mmです。組み合わせた柱の高さは420mmです。枠の外形512×520×420mm、本体4台、140mmファン4個、電源用120mmファン2個は維持します。

## 梁を先に入れ、上側の柱で閉じる

下側の柱を置き、奥行梁を前・中・後の順に上から入れます。横梁も左・右の順に入れ、最後に上側の柱を載せます。柱と梁の抜け止め、二股の固定は内側か下面のねじです。参照CADでは20箇所のM4固定具を置き、相手のナットを貫通する長さまで確認しました。ねじ山は外形の円柱で表した仮モデルで、購入品の実寸や締付け力は未検証です。

リング時から受け梁を組みます。リングの上段ファンは受け板と重なるため、板は載せません。スイッチ導入時は上段を220mm間隔へ移し、板とスイッチを追加します。柱を組み直す必要はありません。

## 受け板を支えながら後ろへ取り出す

通常時は後ろ側の固定ねじ2本で受け板を横梁へ留め、スイッチを保持バンド2本で板へ留めます。バンドは幅20・厚さ1mmの仮外形です。実物の吸排気口と重ならない位置、材質と耐熱性は確認が必要です。

交換時は、電源・通信ケーブル、保持バンド、受け板の固定ねじ2本を外します。板と本体を下から手で支えながら後方へ引き出します。後方500mmで板の前端がフレームの外へ抜けます。取り出し経路に加え、作業場所の確保も必要です。

この板は全開時の荷重を自立して支える引出しではありません。途中からは作業者が荷重を受けます。柱やファンを外さず通過できることと、作業者が支えずに引き出せることを混同しません。

## 検査は形状と接触まで

支持部の閉じた形状、部品間の干渉、水平な受け面、ねじとナットの到達、504点の上からの挿入経路を検査しました。受け面は柱と奥行梁が各224mm²、横梁と奥行梁が各約208mm²です。

CRS804とCRS812の配置では、全体の参考機器との干渉、101点の後方交換経路、短い工具の仮外形の経路、保存後の再読込を確認しました。5kgの仮荷重の静力学分配も記録しています。材料強度、たわみ、長期の変形、振動、冷却の検証ではなく、5kgを耐荷重として表示しません。

購入品の根拠は[MikroTikのCRS812取扱説明](https://help.mikrotik.com/docs/spaces/UM/pages/340492410/CRS812-8DS-2DQ-2DDQ-RM)と[CRS804寸法図](https://cdn.mikrotik.com/web-assets/product_files/CRS804_dimensionsR0_260152.pdf)です。CRS812には机上設置の案内もあります。奥行268mmと156mmの食い違い、取付耳、底面脚、吸排気口、実コネクターは未確定のままです。

生成は`mise run overview:spark-rack`です。同じ実行に、支持部を含む全体図、3配置のFreeCAD文書、スイッチ配置のSTEP、`switch-support-validation.json`、生成記録を保存します。支持部の正本は[寸法定義](../source/switch_support_parameters.py)、[形状](../source/freecad_switch_support.py)、[検査と保存](../source/build_switch_support_cad.py)です。造形用ファイルは出力しません。
