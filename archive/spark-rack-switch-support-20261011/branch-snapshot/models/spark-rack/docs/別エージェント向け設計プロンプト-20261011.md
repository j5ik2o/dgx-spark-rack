# 別エージェント向けの4台ラック設計プロンプト

以下をそのまま別エージェントへ渡してください。購入条件の記録は[注文済み機器と必要数](../reference/ordered-network-equipment-20261011.json)です。

---

DGX Sparkを4台収容するラックの設計案を出してください。既存案の寸法に合わせる必要はありません。購入済み・手持ちの機器、配線、冷却、組立、保守を含めて、実際に使える全体構成を検討してください。

## 本体・接続方式

- DGX Sparkは4台です。2列×2段を第一候補とし、4台を一つの共通フレームで支えます。1台用ラックを連結して増設する方式は不要です。
- スイッチはMikroTik CRS812-8DS-2DQ-2DDQ-RMを1台注文済みです。CRS804への対応は必須ではありません。購入先は[GETICの製品ページ](https://www.getic.com/product/mikrotik-crs812-8ds-2dq-2ddq-rm)です。
- スイッチ接続用に、NADDODのMikroTik互換分岐ケーブルQ2Q56-400G-CU2、2m品を注文済みです。[NADDODの製品ページ](https://www.naddod.com/products/103563.html)を確認してください。400ギガビット毎秒のQSFP-DDコネクターから、200ギガビット毎秒のQSFP56コネクター2端へ分かれる銅線のダイレクトアタッチケーブルです。
- 注文本数は未提示です。1本でSpark側は2端なので、4台をこの分岐ケーブルだけでつなぐ場合、必要数は2本です。必要数を注文数・所有数として扱わないでください。スイッチ側の分岐設定、必要なソフトウェアの版、実機での通信確認も別途整理してください。
- 当面は4台の直結リング接続も使います。手持ちのQSFP112ダイレクトアタッチケーブル40cmが4本あります。メーカーはELSA製と思われますが、型番、コネクター寸法、曲げ条件は未確認です。
- 40cmの長さ制約はリング側です。スイッチ側は注文した2m品を前提に、余長と分岐位置を収容してください。両方式の配線図と、切り替え作業を示してください。

## 収容する機器と電源

次の全項目について、支持する部材、固定、配線、放熱、取り外し経路を設計してください。図に箱を置くだけで完成扱いにしないでください。

1. Spark本体4台。参考寸法は各150×150×50.5mm、質量1.2kgです。足、通気口、背面端子の位置は実測前です。
2. Spark用240W交流電源アダプター4個。ラックの内部へ収めたいです。既存資料の参考寸法は99.05×98.99×35.17mm、質量542.3g、固定されたUSB Type-C電源ケーブルは約1.8mです。公開記事に基づく値で、製造公差付きの図面や実物適合の確認はありません。プラグとケーブルの余裕も含めてください。
3. CRS812を1台。参考筐体寸法は443×268×44mmですが、公式取扱説明に奥行156mmの記載もあり不一致です。取付耳、底面脚、端子、突出部を含む寸法は未確認です。電源は内部に2系統あり、交流電源ケーブル2本を使います。別置きのスイッチ用電源アダプターがある前提にはしないでください。
4. 140mmファン4個。Spark用に各1個を用意する予定です。既存の型番はNoctua NF-A14x25 G2 PWMで、厚さ27mm、取付穴の間隔124.5mmです。本体よりファンが大きいので、通風口へ風を寄せる導風も検討してください。
5. 120mmファン2個。Spark用電源アダプターの冷却用です。既存資料はNoctua NF-A12x25 G2 PWM PPA/PPB、厚さ27mm、取付穴の間隔105mmです。用途をSpark本体用へ変更しないでください。
6. ファンコントローラーとケース。既存方針はファン1個にコントローラー1個で個別制御するため、必要数は合計6個です。6個の所有確認ではありません。温度センサー付き基板は76×25mm、既存ケースは取付耳を含む長さ100mm、幅39.4mm、つまみを含む厚さ29.5mmです。共通ドックは幅43.4mm、厚さ11mmです。つまみ・端子・センサー線の操作と交換も含めてください。
7. ファンコントローラー用の交流電源アダプター。これもラックに収めてください。既存構成はコントローラー2個に12V・3A電源1個、直流電源の二股ケーブル1本、基板接続用の直流電源ジャック付きケーブルは各コントローラーに1本です。この構成を6個へ拡張するなら電源3個、二股3本、ジャック付きケーブル6本が必要です。電源の所有数・寸法・形状・極性は未確認なので、調整可能な保持部と必要な実測を提案してください。電流容量と配線を根拠に給電方式を変更する案も比較できますが、ファンごとの個別制御は維持してください。

既存給電方式を使う場合、交流電源の差込口はSpark用4口、スイッチ用2口、コントローラー用3口の合計9口が基準です。電源タップの寸法、プラグ同士の干渉、容量、接地、操作、配線の保持も検討してください。電源の定格出力と実際の消費電力は区別してください。

## 配線・構造・保守の条件

- リングは隣接する4台を一周させる配線を第一候補にしてください。端子間の直線距離だけで40cmに届くと判定せず、コネクター、真っすぐ引き出す部分、曲げ、抜き差し空間を含めて経路を示してください。未測定値は仮定として明記してください。
- 2m分岐ケーブルは幹線・枝線それぞれの長さと分岐位置、公称長の測定基準が未確認です。シリーズ資料の最小曲げ半径は37～42mmなので、個別確認まで42mm以上を仮条件として検討してください。余長を小さく折り畳まず、通風や保守を塞がない保持経路を用意してください。
- スイッチは自重を支える部材と、ずれ・浮き上がりを抑える固定を含めて設計してください。宙に浮く配置やケーブルで支える配置にしないでください。取り外す際にどのねじ・バンド・配線を外すか、途中で手による支持が必要かも説明してください。
- 3次元プリンターの造形範囲に合わせて部材を分割してよいですが、別部品の継ぎ手や外側の固定板を大量に並べる構造は避けたいです。柱の穴と梁のほぞ、段差で荷重を受ける接合、内側か下面からのねじを第一候補にしてください。最後の部材まで差し込める組立順序と、横方向の変形を止める方法を示してください。
- 以前の512×520×420mmの外形、28mm角の部材、中央の3mmアルミ支持板、上段を持ち上げる切替方法は比較用の旧案です。今回の必須寸法ではありません。2m品で配線の制約が変わるので、外形を小さくできるか、段を移動せず両方式を使えるかも検討してください。
- 未測定の端子横ずれを梁の固定穴に刻まないでください。位置を調整できる方法か、実測後に穴位置を決める方法を提案してください。
- 本体、電源、スイッチ、ファン、コントローラー、全電源ケーブルの支持と固定を含めて、荷重が床へ伝わる経路を説明してください。通気、ケーブルへの力、振動、樹脂の変形、転倒、温度による変化も設計に関係する範囲で検討してください。
- 試験片の印刷と実物試験は後回しです。いまは全体の案と寸法、構造、検査方法まで進めてください。計算上の形状検査と、実物の適合・強度・冷却・通信の確認を区別してください。

## 出力してほしいもの

- 配置や支持方式が異なる2～3案。推奨案を先頭にし、外形、配線、冷却、部品数、組立、保守の6項目で比較してください。各案に全電源アダプターを含めてください。
- 推奨案の全体図、正面・側面・背面・上面の寸法図。可能なら回転・表示切替できる図、または三次元の設計モデルも示してください。
- 各機器の支持と固定の詳細、荷重の流れ、組立順序、Spark・スイッチ・電源・ファンを交換する手順。
- リング運用とスイッチ運用それぞれの配線図、ケーブル保持と余長の置き場、切替手順。
- 印刷部品、購入部材、ねじ、配線の一覧。必要数、所有・注文の確認済み数、未確認数を区別してください。
- 採用寸法の出典、仮定、必要な実測、検査結果、未検証事項。取付耳や曲げ半径などに資料の食い違いがあれば、それを残してください。
