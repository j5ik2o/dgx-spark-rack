# DGX Spark 4台＋CRS812 DDQ 一体ラック 設計提案 v2

既存案（512×520×420mm・28mm角材・中央段スイッチ・CRS804兼用）には縛られない独立案です。CRS812だけを対象に寸法を決め直しました。正本は `source/`、生成物は `build/spark-rack-v2/<実行ID>/`（manifest.json・validation.json付き）です。**この資料の検査はCAD上の形状検査です。耐荷重・冷却性能・実物の適合は保証しません。**

記号: **C**=確認済み条件、**P**=公開資料の参考値、**A**=仮定、**M**=実測待ち（詳細は `reference/specs_v2.json`）。

## 1. 推奨案（案A）の要約

- **外形 490(W)×400(D)×540(H)mm**、側板込み幅494mm、設置面積0.196m²。コントローラーを含む最大幅は約580mm。
- 構造は**2020アルミ押出材の箱形フレーム**（柱4・梁20）。梁は柱の内側へ**ブラインドジョイント**（梁端M5タップ＋柱のアクセス穴）で留め、外へ張り出す継ぎ手板はありません。棚とトレーは梁上面の段差で荷重を受け、抜け止めは下面からT形ナットで締めます。
- **上から順に**: CRS812（3mmアルミ受け板・最上段）／分岐ケーブル余長トレー（背面上部）／Spark 2列×2段（段ピッチ144mm）＋各段前面に140mmファンと導風ダクト／下段: 電源アダプター4個の通風トンネル（120mmファン2個、左吸気→右排気）、コントローラー電源3個、電源タップ。
- **Sparkとスイッチの端子はすべて背面**を向けます（スイッチは端子面を背面へ回して設置）。スイッチの電源2基・ファン4基は前側から交換します。
- コントローラー6個は**既存ケースと共通ドック（M4ピッチ28）を無変更で使用**し、側板外面の前寄りに左右3個ずつ縦向きに付けます。

## 4. 荷重経路・固定・脱落防止

- **スイッチ**: 本体(仮4.0kg)→3mm受け板→左右の側梁（2020, Z440）上面→ブラインドジョイント→柱→脚。受け板は下面からM5×4本で側梁スロットへ留める（上から見えない）。前面取付耳は外し、筐体側面の小型後部支持耳（付属品）の穴を使って**印刷の側面保持**へ固定し、前後滑りを止めます（穴位置M）。宙に浮く支持はありません。
- **Spark**: 本体→印刷トレー（前後端が受け梁上面に載る段差）→前後受け梁(450mm)→側梁→柱。トレーは下面からM5で梁へ抜け止め。トレー上の低い縁で横ずれを止め、Spark底面の足の位置に逃げを設ける（足位置M）。
- **電源アダプター**: トンネル内の棚→トンネル→底板。トンネルは底板へ下面からねじ止め。
- **位置決め突起だけに荷重を掛けない**: すべて梁上面の面受けで荷重を受け、突起は位置決めのみ。
- 樹脂部品の常時荷重はSparkトレー（1.2kg/枚）だけで、梁間スパンは150mmのうち載荷部が短い。PETGはSpark底面温度でクリープの恐れがあるため**ASAまたはPC系を推奨**（耐熱80℃以上）。

## 5. 冷却と導風

- 140mmファン（前面）→ロフト形ダクト（142角→150×約46の吸気口へ絞る、長さ46mm）→Spark前面。ファン風が高さ50mmの本体の上下を素通りしないよう、ダクト出口をSpark前面の吸気範囲に合わせます。**実機の吸気口範囲が未確認（M）**のため、出口開口はダクト交換で調整できるようにファンとダクトを一体の着脱モジュールにしています。絞り比が大きいため静圧が上がる点はファン選定（G2の静圧特性）で受ける前提で、流量は実測が必要です。
- Spark背面排気は背面配線域へ。背面直後20mmは「排気確保」範囲として、ケーブルやコネクター本体以外を置かない検査をしています。ケーブルは端子から真後ろへ出し、左右の外側と列間へ振り分けます。
- 電源アダプター: 左側面吸気→トンネル→右側面排気。吸排気口はSpark吸気（前面）から最も遠い後方寄り。右側面外60mmと左側面外60mmに物を置かない運用条件です。
- スイッチ: 吸排気方向は未確認（M）。最上段に置き、3mm受け板で下段と仕切るため、スイッチ排気がSpark吸気へ戻る経路は前面上部のみ。前面からの排気だった場合は、前上部に上向きのルーバー（印刷）を付けて天方向へ逃がす追加部品を想定しています。
- **冷却性能の保証ではありません**。実機で各Spark吸気温度・本体温度・ファン回転数を測る必要があります。

## 6. 配線

図: `wiring_ring_vs_switch.png`（背面視）。

### リング運用（途中状態）
- 40cm QSFP112 DAC×4で 1段左→1段右→2段右→2段左→1段左。端子の向きはすべて背面。
- 横渡し(中心距離180mm)の必要長目安366mm（直線引出し70mm×2＋曲げR40の半周を仮定）、縦渡し(144mm)は330mm。**端子のX/Z位置、ケーブルの曲げ半径と測定基準は未確認**で、余裕34mmは仮条件での値です。足りない場合は列間を詰めず、横渡しを列間の溝へ斜めに通す、またはスイッチ運用を先行します。
- スイッチ受け板・側面保持はリング時も取付済み（後から骨組みを変えない）。

### スイッチ運用（完成形）
- Q2Q56-400G-CU2×2：QSFP-DD 1口→左列2台、もう1口→右列2台。幹はスイッチ背面から真後ろへ出し、背面配線域を下ろして分岐。
- 経路長の目安 572〜896mm、余長 約1.1〜1.4m/枝（**分岐位置と幹・枝長が未確定**のため、幹＋枝を公称2mとした概算）。余長は背面上部の余長トレーにR42以上の8の字で収め、トレーが重みを受けるため端子へ張力を掛けません。トレーはSpark排気の上流ではなく上方、吸気(前面)の反対側。
- 分岐設定（RouterOSでの2×200G分割）、端子認識、Spark側の通信確認は**機械配置とは別の確認項目**です。

### 電源
- タップ9口: Spark電源4（C6/C5コード, トンネル前側からタップへ）、コントローラー電源3、スイッチ2（IECコード2本、前面上部→左前柱スロット沿いに下ろす）。リング時は7口。
- 消費電力の目安は定格の合算ではなく実測で決めます（スイッチは公称最大134W, Sparkは実測要）。タップの容量は15A品を条件とします。
- USB-C（1.8m固定）はトンネル後部から背面配線域の左右外側をクリップで上げ、各Sparkへ。余長は背面左右の柱スロットへ縦に束ねます（排気確保範囲を避ける）。
- コントローラー電源の3系統: 系統1=左列140mm×2（左側面の1段/2段コントローラー）、系統2=右列140mm×2、系統3=120mm×2（左右下のコントローラー）。各系統は12V3A→二股→DCジャック付きケーブル→端子台。分岐するのは電源のみで制御信号は分岐しません。NF-A14x25 G2/NF-A12x25 G2は定格電流がいずれも0.2A前後（Noctua公表値、要確認）で1系統2個＋コントローラー2個は3Aに十分余裕があります。

## 7. リング→スイッチ切替手順

1. 全Sparkを停止、リングの40cm DACを4本外す（保管）。
2. スイッチを前側から受け板へ載せ、背面へ端子を向けて後方から差し込み位置まで送り、側面保持へ固定（リング時に保持部・受け板は装着済み）。
3. スイッチAC2本を左前柱沿いに下ろしてタップへ。
4. 分岐ケーブルの幹をQSFP-DD 2口へ挿入、背面配線域を下ろし、枝を各Spark背面へ。余長を余長トレーへ収納。
5. 通電→RouterOSで分割設定→リンク確認→Spark間通信確認。
部品の作り直し・骨組みの組み直しはありません。逆向き（スイッチ→リング）も同じ手順の逆です。

## 8. 組立順（最後の部材まで入る順）

1. 柱4本に脚を付け、下枠（前後梁・側梁）をブラインドジョイントで締結 → 底板を下面から固定。
2. 下段機器: コントローラー電源・電源タップを底板に固定、アダプタートンネル3分割を段差はめ合いで連結し底板に固定、120mmファンを両端に装着、電源アダプター4個を棚へ。
3. 1段の側梁・受け梁→Sparkトレー→Spark→背面ケーブル→ファン＋ダクトモジュール。2段も同様。
4. 余長トレーを2段側梁へ吊り下げ固定。
5. スイッチ棚の側梁・前後梁→受け板（下面ねじ）→側面保持。
6. 天枠（前後梁・側梁）。**天枠は最後**で、スイッチは天枠装着後も後方から出し入れできます（検査済み）。
7. 側板（T形ナットを柱スロットへ内側から）→共通ドック6個（M4×25）→コントローラーケース（M3皿ねじ）。
ブラインドジョイントのアクセス穴は柱の内側面に開け、外観に出しません。

## 9. 交換手順と作業空間

- **スイッチ**: 背面ケーブルとAC2本を抜く→側面保持のねじ（受け板下面側）を外す→後方へ水平に420mm引出し（検査: 干渉なし）。電源・ファンだけなら前面から交換（前面60mmの作業空間を確保）。
- **Spark**: 背面ケーブル2本とUSB-Cを抜く→ファン＋ダクトモジュール（M4×4）を前へ外す→Sparkを前へ200mm引出し（検査: 干渉なし）。
- **140mmファン**: モジュールごと前へ外し、作業台でファンのみ交換。
- **電源アダプター**: トンネル後端の蓋を外し、後方へ引出し（検査: 160mm干渉なし）。
- **コントローラー**: 外側からM3皿ねじ2本、外向き30mmの操作空間を確保。
- **コントローラー電源**: 前方へ80mm引出し（検査済み）。

## 12. 実物検証へ進む条件

1. CRS812の実奥行（268/156）、側面の後部支持耳の穴位置、底面脚、吸排気方向、質量を実測。
2. DGX Sparkの吸排気口の範囲・方向、底面の足位置、背面端子（QSFP×2、USB-C）の位置を実測。
3. 40cm DACの型番・曲げ半径・コネクター外形・長さ測定基準を確認し、リング横渡しの余裕を再計算。
4. Q2Q56-400G-CU2の注文本数（2本必要）、2m型の曲げ半径、分岐位置と幹・枝長、ラッチ外形を確認。
5. コントローラー電源・タップ・プラグの外形と極性・ケーブル長・コントローラー消費電力を実測。
6. 140mmファンの全数、コントローラー6個の所有数を確認。
7. 上記をパラメーターへ反映して再生成し、検査を通過させる。
8. その後にトレー・ダクトの試験片印刷（材料: ASA/PC）、押出材の発注、通電前の荷重・たわみ確認、通電後の温度測定。

## 13. 既存資料との関係

- 共通ドックとケースは `tools/cad/controller_mount.py` の規格（M4ピッチ28、M3ピッチ92）のまま使います。側板(2mm)へM4通し穴を開けるだけで、ドック・ケースの変更はありません。M4×25は板厚2mm＋ドック11mm＋ナットに対して長さに余裕があるため、M4×20でもよい（要確認）。
- 旧資料の「ケース4個・電源2系統」は140mmファン2個時代の構成のため採用せず、6個・3系統としました。
- 既存ファイルは編集していません。
