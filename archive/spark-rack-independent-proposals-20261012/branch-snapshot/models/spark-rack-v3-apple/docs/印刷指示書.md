## 2. 荷重の向きと造形向き
- **トレー・保持部品**: 荷重は層の面内に掛かる曲げなので、平置きにします。
- **L字ブラケット**: 折れ部分を層の面内に置くため、横倒しで造形します。立てて印刷すると層間がはがれる向きになるので禁止です。
- **トンネル**: 筒の軸を縦にします。側壁に層の線が連続し、上からの荷重は壁の面内で受けます。
- **ダクト**: 荷重はほぼ掛かりません。ファン（約200g）の支持はフランジ面で受けます。

- 圧入温度はPAHT-CFの場合、約260〜280℃（インサートのメーカー推奨を優先）。垂直に押し込み、圧入後に24時間置いてからねじを締めます。

## 4. 推奨設定（PAHT-CF、X1C）
- **ノズル**: **0.4mm硬化鋼ノズル必須**（炭素繊維入りのため。真鍮ノズルは不可）。AMSはCF材の対応可否を確認し、外部スプールの使用を推奨。
- **乾燥**: **80℃・8〜12時間**（印刷前に必ず実施）。印刷中もドライボックスから直接供給。PAHT-CFは吸湿が早いので、開封後は湿度20%以下で保管。
- **温度**: ノズル260〜290℃、ベッド80〜100℃（Bambu PAHT-CFの推奨値を優先）、チャンバーは閉め切り。プレートはEngineering／High Tempにのり（接着剤）を塗布。
- **層高さ**: 0.20mm（表示窓枠は0.12mm）。
- **壁**: 4本（トレー・ブラケット・保持部品・トンネル）、3本（ダクト・余長トレー・窓枠）。
- **上下層**: 各5層。
- **インフィル**: ジャイロイド40%（ブラケット・保持部品は60%）。ダクトは壁のみでも可。
- **ブリム**: トンネル・余長トレーに5mm（反り防止）。
- **印刷後の処理**: 強度と寸法安定のため、80℃で数時間アニールを推奨（任意）。吸湿すると靭性が戻るため、使用環境で数日なじませてから寸法を確認。

## 6. 先に試し印刷する部品（フィット確認）
1. **表示窓枠1個**: インサートなし。透明PC板（1mm）の落とし込みと、前面パネル窓との合いを確認。
2. **L字ブラケット1個**: 共通ドックのM4穴ピッチ28、M4インサートの下穴、側壁穴との位置を確認。
3. **Sparkトレー1個**: Sparkの底面の足とリップ、プランジャーのくぼみ、梁上の案内との合い、つまみの指掛け。**Spark実機と梁の実物で確認**。
4. **導風ダクト1個**: 140mmファンの穴（124.5ピッチ）、Spark前面吸気口との位置、固定タブ。
- 寸法がずれていたら `rack_v3_parameters.py` と `printed_parts_v3.py` を直して再生成してください。STLや3MFだけを修正するのは不可です。
