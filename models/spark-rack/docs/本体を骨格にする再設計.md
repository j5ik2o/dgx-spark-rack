# Spark本体の角をつなぎ、2台積みを2列にする

2026年10月19日のユーザー指定に基づく新しい設計候補です。筐体を外枠へ入れる方式から、本体の側面と上下の面へ局所接続部を当てる方式へ変えます。現在は全機器を含む参考配置と接続部の形を確認する段階で、造形用のファイルは生成しません。

Spark4台、CRS812、GL-RM10、TESmart HKS401-P23、電源アダプター4個を維持します。ファン140mmを4個、120mmを2個、制御器6組は従来の設計条件を引き継いだ初期案です。現在の所有数を再確認した記録ではありません。[合意した方向性](../reference/body-frame-requirements-20261019.json)と[機器の出典・未確定値](../reference/pending-mount-measurements.json)を入力にしています。

## 接続部だけでは全段を支える外枠にしない

接続部は下段の脚、上下段の間、上段の上に分けます。左右の列の内側では、2つの角を1つの部品でつないで列同士を結びます。背面を開放するため、背面側の接続部は側面と上下の面だけへ当てます。

上段の支持は、上段の筐体、上下段の接続部、下段の筐体、脚の順につながる想定です。Spark用ファン保持部は中間の接続部だけへ、電源用ファン保持部は脚の接続部へ付けます。筐体を含む接触関係がつながり、筐体を除くと複数の群に分かれることを検査します。

これは接触関係の確認です。はめ合いの適合や、外装が荷重を支えられることの立証にはなりません。Spark外装の荷重許容、足・丸み・通気口、接触箇所の変形を確認するまでは製造へ進めません。

## 組立用のビス・ナットを使わない

ユーザーの指定により、現行案のラック・ファン取付・制御器ケースの組立用ビスは0本、ナットは0個とします。[ねじ不要の条件](../reference/body-frame-screwless-20261019.json)を入力へ加えました。購入機器内部のねじを分解して取り除く変更ではありません。

過去の[ほぞと段差の試験片](凹凸の接合試験片と次案.md)の考え方を引き継ぎます。現在の部材に合わせて形状を作り、旧形状コードは生成元へ読み込みません。印刷範囲に入る接触部は一体化し、分割が残る箇所はほぞを差し、横から角栓を入れて引き抜きを止めます。重さは段差の面で受け、細い栓だけに支えさせません。

| 対象 | ねじを使わない固定方法 |
|---|---|
| 骨組みと受け | 一体化、または受け面を残したほぞ差しと角栓 |
| ファン | ねじ山のない樹脂割りピンを取付穴へ各4本。返しを二股にして解除する候補 |
| 制御器の基板 | 基板押さえ4か所を蓋と一体にし、基板上面へ0.2mmの遊びを残す |
| 制御器の本体・蓋・受け台 | ねじ穴を加工しない形状と、解除式結束バンド2本ずつ |
| CRS812・配線 | 既定の保持ベルトと解除式結束バンド |

角栓が入った状態ではほぞの引き抜きが止まること、ファンの割りピンの頭と返しが相手に掛かることを形状で検査します。制御器のねじ穴・ナット穴を使わないことも検査します。角栓の固さと脱落防止、割りピンの弾性、手で支える操作、材料と積層方向は実物で未確認です。角栓の脱落防止に必要な箇所は解除式結束バンドも併用する条件とし、試作で決めます。造形用の出力はまだ行いません。

## 小組みを先に作り、最後の部材と角栓まで通す

[ねじ不要ラックの組立順](ねじ不要ラックの組立順.md)に、小組みと搭載の手順をまとめました。作業台での接合20工程と搭載22工程を参考形状へ再適用し、検査対象の剛体110個を手順へ含めます。部材を合わせるたびに角栓を差し、ベルトと配線は最後に固定します。

上部支持部の1か所は、上下から挟む形で縦方向へ差せなかったため、横差しのほぞに修正しました。中間連結部の角栓も、一体ガイドへぶつからない差し込み側へ変更しています。開始・終了位置だけでなく、移動途中の領域を検査します。剛体形状の経路が通ることと、実物のはめ合い・弾性・強度は区別します。

## 指で角栓を扱う空間も形状へ含める

角栓へ幅10mm・長さ6mmのつまみを加え、つまみを挟む二指を各12×10×12mmの仮の箱で表します。つまみは受け面から4mm離して始め、必要箇所は接合面の法線方向へ8mmずらします。各接合工程で栓と指の経路、着座後に指だけ離す経路を検査します。ファン用の角栓は完成状態での直線引抜きも検査し、羽根を省略した参考ファンの空洞へ指を通して合格させません。

制御器の解除式バンドは解除頭を表示面と同じ外側へ向け、その前へ操作空間を予約します。CRS812のバックルは上から操作する予約を加えます。指の箱は人体寸法の規格値ではなく、購入品の解除機構、実際の手の動き、操作力と強度は未確認です。詳細は[組立順と操作空間](ねじ不要ラックの組立順.md)に記録します。

## 肉厚と造形方向を部品ごとに確認する

[肉厚と造形方向](肉厚と造形方向.md)に、ラック・栓69個と制御器ケースの本体・蓋12個の方針をまとめました。1本だけ0.99mm角だった角栓をなくし、中央断面を1.8mm角以上にそろえます。角栓と割りピンには全長を接地する平面を追加します。本体間の上下の隙間を20mmへ広げ、配線予約も再検査します。造形姿勢は81個をブラウザで個別に確認できます。支持材、印刷経路と実物の強度は確認前です。

## 支持材は接合口を避け、小分けにして外す

部品分割を維持したまま、[支持材を置く領域と除去順](支持材の配置と除去.md)を追加しました。機器へ向く面、ほぞ、角栓の通路、ファン取付穴を保護します。残っている領域と部品を避け、ペンチ先端の仮外形も含めて外へ引き出す経路を検査します。支持材の構造、精密面の橋渡し、実際の除去力は確認前です。

## 本体は近接した2段、周辺機器は上部と下部へまとめる

| 対象 | 配置候補 |
|---|---|
| Spark | 左右2列、上下2段。本体間の隙間は左右20mm、上下20mm |
| 下段・上段の底面 | 設置面から60mm・130.5mm。本体部分の高さは121mm |
| 電源4個 | 本体の下、左右2列・前後2個。個別の開放した受けへ載せる |
| GL-RM10 | 本体の上、前側の小さな載せ台 |
| TESmart切替器 | GL-RM10より後ろ。300×117×30mmの未実測参考値 |
| CRS812 | 最上部の左右レール。443×268×44mmを参考外形に使う |
| 制御器6組 | 左右各3個。正本のねじ不要ケースと受け台を正立配置 |

画像にあった制御器6個の横一列配置は、そのまま寸法の正本には採用しません。受け台の長さは1組100mmあり、横一列では本体の幅を超えます。この候補では左右へ分けて保持します。

CRS812の奥行は資料間の不一致が残り、取付耳を含む幅や足の位置も確認前です。参考外形の底面がレールに当たっていても、実物の足で支持できると判断したものではありません。

## CRS812は低い抜け止めとベルトで軽く固定する

ユーザーの追加条件は、最上段のスイッチが横滑りして落ちない程度の簡単な固定です。机へのクランプは対象に含めません。支持レールに前後左右の高さ8mmの抜け止めを設け、非伸縮の着脱式ベルト2本で本体とレールを一緒に抱く案にします。筐体との仮の隙間は0.5mmです。レールは造形範囲に収めるため前後に分割します。

ベルトは機器だけを巻くのではなく、支持レールの下側まで回します。取り出す際はバックルを開き、抜け止めを越えるまで持ち上げます。図中の帯とバックルは購入品の参考形状で、印刷部品ではありません。ベルトの幅・厚さ・バックル寸法は仮定で、製品・締め付け・耐荷重は未確定です。

参考外形を水平4方向・上方向へ2mm動かすと保持部に当たること、ベルトが本体の上面と支持レールの下側に掛かることを形状で検査します。これは軽い保持の形状確認で、実際の振動・強度試験ではありません。足や通気口、抜け止めとの接触、緩みや変形は実物で確認します。同じ震度でも揺れの振幅・周期・継続時間などによって状況が異なるため、特定の震度を単一の荷重や形状検査の合格値へ変換しません。[気象庁の留意事項](https://www.jma.go.jp/jma/kishou/know/shindo/kaisetsu.html)と[ユーザー条件・検査範囲](../reference/body-frame-switch-retention-20261019.json)を記録します。

## ファンは正立固定し、軸方向へまっすぐ外す

前後のファンは本体の前後面に、左右のファンは側面に平行な垂直面へ固定します。斜め取付と、ヒンジで開いた運転姿勢は使いません。生成時に取付軸と実形状の外形を検査し、軸の記録だけを正しくして実形状を斜めにした場合も拒否します。保存後のFreeCAD文書にも固定取付と軸を記録します。

| 対象 | 個数・向き |
|---|---|
| Spark用140mm | 各列の前面と背面へ各1個、合計4個。2台の列を挟む配置候補 |
| 電源用120mm | 電源区画の左右へ各1個、合計2個 |
| 着脱 | 配線と保持部の角栓を外し、取付面に垂直な方向へ引く。ファン単体は樹脂割りピンを解除する |

着脱は20mm、50mm、110mmの位置で固定物と干渉しないことを検査します。この離散的な着脱検査だけでは、角栓や割りピンを実際に解除する操作は確認できません。全体の組立順は、別の組立経路検査で扱います。

前面は指の操作空間のため本体から30mm、背面は配線のため230mm離す候補です。前面の間隔は15mmから広げたため、全体の奥行は15mm増えます。近接ファンによる送風が、従来案の前方100mm・後方400mmの空間を確保する方式と冷却上で同等だとは判断していません。排気の再吸込み、温度、性能、騒音は実物で確認します。

## 下段の交換には上部の分解が必要になる

本体を構造の一部にするため、下段だけを独立した棚から引き出す方式にはしません。下段を外す際は上部機器と上段を先に外す、または上側を仮支持する手順が必要です。運転したままの交換は想定していません。

背面端子用には本体の高さと幅に沿う奥行60mmの仮空間を予約します。実端子・プラグが収まることを保証する値ではありません。

## 配線経路と余長の置き場を分ける

ユーザーが「配線を含めて配置を詰める」を選択したため、機器の配置だけでなく、42系統の経路予約と開放式の保持部を追加しました。通信、映像とUSB、直流電源、交流電源、ファン制御を色分けします。図の管は束の通過領域です。実線径と束の内部配置は未確認で、束同士の重なりを許した予約です。

ユーザーの選択により、配線固定は[解除して再使用できる結束バンド（インシュロック）](https://www.hellermanntyton.co.jp/product/cabletie/repeat/rf.html)を標準にします。保持部の穴へ通し、切断せずにロックを解除して外す方式です。解除レバーを保持部の外側から操作できる向きに配置する条件を加えます。太いネットワーク分岐ケーブルは締め付けて固定せず、曲げを維持して緩く保持します。必要なら面ファスナーを併用します。穴は現在8×3mmの候補で、製品、バンドの幅・厚さ、解除レバーへ指が届くことは選定後に確認します。機器本体を押さえる保持ベルトとは別の部材です。

| 対象 | 配線・保持の候補 |
|---|---|
| 高速ネットワーク | 本体背面の外寄りを通し、左右の受けへ分岐点と余長を逃がす。CRS812は通信端子面を背面へ向ける候補 |
| ネットワークの余長 | 半径55mmで左右各3周を予約。仮の線径8mmで、中心線長は片側約1.04m。実際の収納量は未確定 |
| 映像とUSB | 本体から切替器へ背面の束で接続。余長は下部背面の別の受けへ置く |
| 映像とUSBの余長 | 半径30・45mm、4層の予約。仮の束径12mmで、中心線長は片側約1.88m。付属1.5m線の全余長が収まるという判定ではない |
| Sparkの直流電源 | 電源受けを8mm上げ、受けの下を通して背面から本体へ戻す |
| ファン | 固定配線と、着脱コネクターより先の短線を分ける。束の留め板はファン保持部から独立させ、中間の本体接続部へ付ける |
| 電源タップと電源線余長 | 右側の机上へ別置き。360×90×90mmの予約。8口以上と、制御器の補助電源に必要な領域を確保する候補 |

ネットワークの曲げ半径は、[NADDOD製品ページ](https://www.naddod.com/products/103563.html)の37〜42mmに基づき、42mmを暫定の下限とします。主線と分岐線への適用、プラグ、分岐点、各線の長さは実物で確認します。2mを分岐線それぞれの長さとして扱いません。他の線径・曲げ半径、端子中心、プラグ突出35mmは設計上の仮定で、製品の確定仕様ではありません。[配線の仮定と出典](../reference/body-frame-cable-assumptions-20261019.json)に記録します。

機器・保持部・角栓・樹脂割りピンを含む参考外形は、各実行の検査結果とブラウザで確認できます。別置きのタップ、電源線、ファンを引き抜くための操作空間は別に必要です。ブラウザには機器・保持部と、机上タップ・配線を含む設置予約の寸法を分けて表示します。設置予約の寸法はファン取り外しの操作空間を含みません。

各列の中央に幅80mm・高さ105mmの仮の排気通路を予約し、配線と保持部が塞がないことを検査します。実際の通気口を再現した冷却解析ではありません。端末周辺15mmだけは接続用の仮領域として干渉検査から除外します。接続先の筐体全体を検査から除外することはしません。

ファン交換は、電源を切り、対象の着脱コネクターと短線の留め具を外してから、短線をファン側へ寄せ、保持部の角栓を抜いて軸方向へ引く手順です。固定配線と余長予約が、この110mmの連続した移動領域に入らないことを検査します。短線を寄せる実際の操作、実際の手の到達と操作力、固定機構と保持帯の適合は未検証です。ファン単体の樹脂割りピンは、保持部ごと取り外してから作業台で解除します。

タップの8口はSpark用4口、GL-RM10用1口、切替器用1口、CRS812用2口の合計です。制御器の給電仕様によって追加口が必要です。タップの製品、定格、差込間隔、周辺機器の電源アダプター、温度センサー末端の配線は未確定です。

## 次に筐体と接触する部分を実物へ合わせる

この配置を基準に、端子・プラグ・分岐点と各線の長さ、Sparkの足・丸み・通気口・接触可能な面を測り、接続部と保持部を実物へ合わせることを推奨します。その後に短いほぞ・角栓・割りピンの試作で、はめ合い、解除、脱落防止を確認します。周辺機器の位置を変える場合は、支持レールとファンの着脱経路も再検査します。
