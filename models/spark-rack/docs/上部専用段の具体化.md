# 上部専用段は上枠を共有して全高618mmにする

[スイッチ専用段の配置比較](スイッチ専用段の配置比較.md)で推奨候補とした上部専用段を、床、トレー、側枠の受けまで具体化しました。現行枠の上へ積み増すと全高668mmですが、上枠を専用段の上へ移して床を側枠へ差し込むと618mmに収まります。本体の底面208／428mmと電源区画は変えません。

この案は形状候補で、既定の中央配置を置き換えたものではありません。`mise run redesign:spark-rack`は従来どおり中央配置の560mm案を作り、`mise run upper-bay:spark-rack`がこの案を別の出力先へ作ります。造形用のファイルは生成しません。試験片の印刷を後回しにする指定も維持します。

`build/`はGit管理の対象外です。以下の画面と検査へのリンクは作業環境での閲覧用で、新しい環境では後述のコマンドで再生成します。

[今回の形状候補の画面](../../../build/spark-rack/upper-switch-bay/20261012-171745-e38c72b3/fixed-rack.html)、[3案の比較](../../../build/spark-rack/upper-switch-bay/20261012-171745-e38c72b3/upper-bay-variants.json)、[検査結果](../../../build/spark-rack/upper-switch-bay/20261012-171745-e38c72b3/validation.json)を保存しました。

## 積み増しをやめると50mm低くなる

| 案 | 全高 | スイッチ底面 | 床の下端 | スイッチ前側の作業空間 | 高さを決める条件 |
|---|---:|---:|---:|---|---|
| 現行枠の上へ積み増す | 668mm | 584mm | 560mm | 確保 | 現行枠の上端560mm |
| 上枠を共有する（推奨） | 618mm | 534mm | 510mm | 確保 | 前側の作業空間を上段ファン保持部の上端529.25mmより上へ通す |
| 床を最も下げる | 599mm | 515mm | 491mm | 上段のファンと保持部に当たる | 上段Sparkを背面へ出す空間の上端490.5mm |

3案とも、スイッチの下は仕切り4mm、支持帯12mm、トレー8mmの合計24mmです。上方の手の余裕12mmと上枠28mmも同じ値を使います。積み増し案は配置比較の668mmと同じ条件です。

積み増し案では、現行枠の上枠28mmと、上段Sparkの交換空間の上端490.5mmから上枠の下端532mmまでの41.5mmを使いません。上枠を共有する案では、この高さに専用段の床を置きます。

床を最も下げる案は、さらに19mm低くなります。ただし、スイッチ前側の面から電源とファンを前へ出す経路が、上段の140mmファンと保持部に当たります。CRS812の電源とファンが端子側の面にある場合、または部品交換のたびにスイッチ全体を背面へ出すと決めた場合に選べる条件付きの代案です。

## 推奨案は継ぎ目を増やさずに荷重を側枠へ渡す

推奨案は側枠を上まで連続させます。荷重は次の順に伝わります。

スイッチ → 左右のトレー → 床の支持帯 → 床の左右の舌 → 側枠の水平な受け → 側枠の重ね継ぎ → 脚

床の左右の端は、厚さ24mmの舌として側枠へ8mm差し込みます。本体の固定棚と同じく、下面の水平な座で荷重を受け、側面と上面だけに0.3mmの組立隙間を設けます。側枠には高さ498〜534mmに全厚の帯を加えました。通気穴はこの帯の上下に分け、受け面を穴で削りません。受け面の接触は左右それぞれ約3,290mm²です。

側枠の分割位置は変えていません。最上段の板は高さ384〜618mmの234mmで、造形範囲246mm以内です。中央配置で使っていたスイッチ用の受け梁2本（3分割で6部品）は不要になったので外しました。中段の帯は側枠に残しました。この高さには、後から[遠隔操作機器の棚](遠隔操作機器の配置.md)を差し込んでいます。

積み増し案は現行枠を変えずに後から追加できます。ただし部品はまだ印刷していないため、後付けできる利点は小さいと判断しました。積み増す場合は、専用段の側柱を側枠の上端へ載せる重ね継ぎとねじを新たに設計する必要があります。

## スイッチはトレーに載せて背面へ引き出す

[公式取扱説明](https://manual.mikrotik.com/hardware/crs812-8ds-2dq-2ddq-rm/)は、2つの取付方法を示しています。1つは、前側の取付耳と、本体側面に付ける小さい後方支持耳を使い、ラック後側の長い後方支持耳と組み合わせる4点支持です。もう1つは、底面にゴム足を付けて机上へ置く方法です。耳込み幅、耳の穴位置、質量、吸排気方向、電源とファンがどちらの面にあるかは記載がありません。

穴位置が分からない段階では耳の取付座を設計できないため、机上置きと同じ底面支持を候補にしました。

| 部品 | 形状候補 |
|---|---|
| 固定床 | 幅504×奥行411.67×高さ24mm。6分割で、最大192×217.84×24mm。床板4mmで本体区画と専用段の空気を分ける |
| 支持帯 | トレーの外側の縁と中央の継ぎ目の直下に、背面の端まで続く帯。前後にも幅20mmの帯 |
| 側面ガイド | トレーとの隙間0.3mm。床の左右の舌と一体 |
| 前側の止め | トレーの前端から0.3mm前 |
| トレー | 左右2枚で、各233.35×240×8mm。継ぎ目の隙間は0.3mm。窓を開け、側面の止め（厚さ4mm、高さ8mm）を一体にする |
| 抜け止め | トレーの後ろ寄りを、直径4mmのねじ2本で床の後側の帯へ留める。交換時に外す |

トレーの奥行240mmは造形範囲246mmに収めるための値です。参考奥行268mmの場合、スイッチの端子側が28mm張り出します。公式取扱説明の156mmが正しければ、スイッチ全体がトレーに載ります。実奥行を測ってから、前側の止めとトレーの位置を決め直します。

スイッチ本体をトレーへ留める金具は未設計です。後方支持耳を付ける本体側面のねじ穴を実測してから、側面の止めへ固定する方法を検討します。床側の雌ねじは、熱で埋め込むナットかナット保持の候補で未確定です。

## スイッチは背面へ引き出し、前面には部品交換の開口を残す

スイッチは接続を外し、抜け止めねじ2本を外して、トレーごと背面へ引き出します。トレーと一緒に動く範囲を除き、固定した床、ガイド、上枠が引き出し経路に入らないことを検査しました。トレーを20mmずつ背面へ動かしても、床と重ならないことも検査しています。

スイッチのラック前側の面は、前面から約169mm奥にあります。上段ファン保持部の上端529.25mmから上枠下端590mmまで、高さ約61mmの開口が前面に残ります。この開口から電源とファンを前へ出す経路を予約しました。ただし、この面に電源とファンがあるかは未確認です。開口の覆い、配線の引き出し口、外観は未設計です。天面も前後の上枠だけで開いており、スイッチの上面が見えます。天面の覆いは、スイッチの吸排気方向を確認してから決めます。

床板は、本体区画と専用段を分ける仕切りを兼ねます。Sparkの前方100mmと後方400mmの空間、上段Sparkを背面へ出す空間には入りません。背面で上がる本体の排気をスイッチが吸い込むかどうかは、スイッチの吸排気方向が分からないため判断できません。

スイッチの端子面は高さ534〜578mmです。積み増し案の584〜628mmより上段Sparkに近づきますが、分岐ケーブルの到達と余長収納は未検証です。

## 部品数は72から74になる

| 項目 | 中央配置（既定） | 上部専用段 |
|---|---:|---:|
| 外形 | 544×460×560mm | 544×460×618mm |
| 印刷候補の部品 | 72 | 74 |
| 参考形状 | 63 | 63 |
| 形状体積 | 10.636リットル | 13.114リットル |

中央用の受け梁6部品を外し、固定床6部品とトレー2部品を加えました。この表は上部専用段だけの値です。その後に中段の[遠隔操作機器の棚](遠隔操作機器の配置.md)を加えたため、現在の`mise run upper-bay:spark-rack`は83部品を生成します。形状体積は参考形状を除いた値で、充填率、支持材、印刷損失を含む材料使用量ではありません。脚、留め具、開口の覆いが加わるため、製造時の部品数は未確定です。

形状体積は約2.48リットル（約23%）増えました。内訳は次のとおりです。

| 部品 | 増減 |
|---|---:|
| 固定床 | +1.66リットル |
| 側枠（58mm高くなった分と床の受けの帯） | +0.77リットル |
| トレー2枚 | +0.29リットル |
| 中央用の受け梁（外した分） | −0.24リットル |

床板4mmを仕切りとして全面に残したことと、ガイドを舌と一体の中実にしたことが主な理由です。床の仕切りが本当に必要かは、スイッチの吸排気方向を確認してから判断します。不要なら、スイッチの外側の床板に窓を開け、ガイドを薄い壁にして減らせます。

既定の中央配置の生成結果は、配置、支持構造、操作面、形状データとも変更前と同じです。比較元は`build/spark-rack/fixed-rack/20261012-165720-c9ce7a37/`、変更後は`20261012-171849-65b30496/`です。

## 検査した範囲

既定の中央配置と同じ検査に、上部専用段の検査を加えました。

- 閉じた単一形状と、最大246mmの外形
- 部品と参考形状の静止干渉
- Sparkの前後の空間と、本体とスイッチの背面交換経路
- スイッチ前側の作業空間
- 床の舌から側枠への受け面、トレーから床、スイッチからトレーへの接触面
- トレーを背面へ引き出す途中で床と重ならないこと
- 保存後の再読込と、ブラウザー表示の主要操作

これらはCAD上の確認です。強度、長期荷重、重心が上がることによる横揺れと転倒、冷却、実際の交換操作は検証していません。

## 判断を変える未確定値

- スイッチの電源とファンがどちらの面にあるか。端子側なら、床を最も下げる599mm案を選べる。
- スイッチの吸排気方向と、背面で上がる本体排気を吸い込むか。
- スイッチの実奥行（156mmと268mmの不一致）、質量、後方支持耳の穴位置。
- 分岐ケーブルの主線長、分岐線長、端子と分岐部の外形。
- 全高618mmを設置場所で許容できるか。

## 正本から再生成する

| ファイル | 担当する内容 |
|---|---|
| [spark_rack_parameters.py](../source/spark_rack_parameters.py)の`UpperSwitchBayParameters` | 専用段の寸法の正本 |
| [upper_switch_bay.py](../source/upper_switch_bay.py) | 床の高さ、全高、予約空間、3案の比較 |
| [switch_bay_geometry.py](../source/switch_bay_geometry.py) | 固定床とトレーの形状、側枠の受け、ねじ候補 |

配置、側枠、検査は、既定の中央配置と同じコードへ専用段を渡して作ります。

```sh
mise trust
mise run upper-bay:spark-rack
```

`build/spark-rack/upper-switch-bay/<実行ID>/`へ、FreeCADの参考形状、形状交換ファイル、表示画面、3案の比較、配置、支持構造、検査結果、入力と生成物の照合記録を保存します。既存の生成物は上書きしません。

ブラウザー検査は、印刷候補の部品数を2番目の引数に渡します。中段の機器棚を含む現在の生成物は83です。

```sh
node tests/check_fixed_rack_view.cjs build/spark-rack/upper-switch-bay/<実行ID> 83
```

## 次は固定金具と前面の覆いを実物に合わせる

スイッチと分岐ケーブルが届いたら、奥行、質量、電源とファンの面、吸排気方向、後方支持耳の穴位置を測り、[未確定値の記録](../reference/pending-mount-measurements.json)へ書き込みます。電源とファンが端子側にあれば599mm案と比べ直します。その後に、スイッチ本体の固定金具、専用段前面の覆い、配線の引き出し口を設計します。

この案を既定の配置として採用するかは、別に判断します。採用する場合は、中央配置の生成と検査をこの案へ切り替えます。
