# 次案の配置参考は共通基準へそろえる

136部品案は不採用です。現在の進め方は[枠を小型化し、電源を内蔵する次案](凹凸の接合試験片と次案.md)を参照してください。配置の参考表示は下段底72mm・制御ケースの内側位置を共通定義へそろえ、本体の横ずれは0mmを初期値にしました。電源の統合配置は`overview:spark-rack`の画面で確認します。未測定の端子位置を製造穴へ固定していません。以下の旧数値表や構造説明は当時の参考で、採用寸法ではありません。

2列×2段と中央段のスイッチに、本体用140mmファン4個を追加しました。120mmの2個は別置きの電源アダプターラック用へ使います。初期案はリング・CRS812・CRS804の3方式とも、仮の端子位置と曲げ条件では40cm内に収まります。ただし、スイッチ端子を筐体の端まで広げた条件では両機種とも40cmを超えます。実端子位置と曲げ条件を確認する前に、配線が届く設計として確定しません。

## 配置検討画面と参照モデルを生成する

FreeCADの実行環境で、リポジトリのルートから実行します。

```sh
mise trust
mise run layout:spark-rack
```

今回の生成先は `build/spark-rack/four-node-layout/<実行ID>/` です。毎回新しいフォルダを作ります。その中の `four-node-layout.html` をブラウザーで開くと、40cm／50cm、ファンの表示、接続方式、見る方向、左右・上下の間隔、引き出し長、曲げ半径を変更できます。「前面」でファン4個を確認でき、詳細欄で端子の仮位置や余裕も調整できます。

画面内の変更は保存済みのFreeCADモデルへ自動反映しません。「検討値を保存」で比較用の値を残し、採用する寸法を正本のPythonへ反映して再生成します。FreeCADを使わず画面と計算だけ生成する場合は、`python3 models/spark-rack/source/build_four_node_layout.py --without-cad` を実行します。

| 生成ファイル | 確認する内容 |
|---|---|
| `four-node-layout.html` | 配置と配線条件を調整する画面 |
| `four-node-layout-ring.FCStd` / `.step` | 4台のリング接続。スイッチと中央の支持範囲を外した表示 |
| `four-node-layout-crs812.FCStd` / `.step` | CRS812を中央段へ載せる仮配置 |
| `four-node-layout-crs804.FCStd` / `.step` | CRS804を中央段へ載せる仮配置 |
| `layout-report.json` | 端子座標、配線中心線、解析式の経路長、余裕、収容・干渉の検査 |
| `validation.json` / `cad-validation.json` | 初期配置の検査と保存後の再読込検査 |
| `manifest.json` | 入力の正本と出力ファイルの内容照合に使う記録 |

参照モデルにある箱は機器やファンコントローラーの収容範囲、薄板は支持範囲、線は配線中心線です。ファンと保持板は開口と公表取付ピッチを含む参考形状で、ガードも外形の範囲だけを示しています。共通枠の梁、接合部、支持板の通風穴、印刷部品を設計したものではありません。

## 初期案は幅520×奥行530×高さ420mm

共通枠の仮収容範囲は幅520×奥行530×高さ420mm、左右のSpark中心間隔は180mmです。当面のリングでは上下中心間隔を160mmへ詰め、下段の本体底を70mm、上段を230mmに置きます。将来のスイッチ接続では上下中心間隔を220mmへ広げ、上段の本体底を290mm、スイッチの端子中心を高さ205.25mmに置く案です。Sparkの背面とスイッチの接続端子面は同じ面です。

ラックを増設する連結構造は設けません。同じ4台用フレームに支持段を移動できる取付位置を用意する方針です。画面で接続方式を切り替えると段間隔の初期値も切り替わります。実物の固定機構は未設計です。

上下段とも140mmのファンを1台につき1個、合計4個配置します。ファンは防振パッド込み厚さ27mm、ファン後端とSpark前面は25mm離す仮定です。保持板はファン外形の各辺へ6mm加えた範囲、厚さ4mmとし、ガードにも4mmの収容範囲を予約しています。

ファンコントローラー4個と共通ドックは、つまみを含む100×44×43mmの収容範囲として左右の側面寄りへ置きました。既存ケースの設計は保持しています。ケースの実形状やねじ、配線・取り外しの操作空間はこの範囲検査だけで確認済みとは扱いません。

ファンを追加する前の段間隔180mmでは、ファンや保持板がスイッチと支持範囲へ重なりました。段間隔を広げ、Sparkの支持範囲を奥行150mmへ縮めた案では、参照機器・保持板・支持範囲の重なりを解消しています。

CRS812の幅とCRS804の最大奥行を収める共通の案です。機種を選んだ後は、その機種に合わせて幅または奥行を詰める余地があります。背面側には110mmの配線空間を予約しています。

Sparkの2つの端子は、本体中心から横へ30mmずれ、端子間隔24mm、本体底からの高さ25.25mmと仮定しました。この仮端子の中心をそろえるため、Sparkの2列全体を枠の中心から30mmずらしています。端子位置を実測すると、この横位置も変わる可能性があります。

## 余長と公称長の基準差を含めて比較する

端子から直線30mmを引き出し、中心線の曲げ半径20mmで2つの四分円を作り、その間を直線でつなぎます。計算した経路長に余長30mmと公称長の測定基準の差に備える40mmを加え、公称長の400mmまたは500mmから差し引きます。すべての曲げ条件と予約量は仮定です。

| 接続方式・条件 | 4経路の最長必要長 | 400mmに対する残り | 500mmに対する残り |
|---|---:|---:|---:|
| リング・段間隔160mm・仮端子 | 312.8mm | 87.2mm | 187.2mm |
| リング・段間隔220mm・比較用 | 372.8mm | 27.2mm | 127.2mm |
| CRS812・仮端子 | 330.9mm | 69.1mm | 169.1mm |
| CRS804・仮端子 | 278.4mm | 121.6mm | 221.6mm |
| CRS812・スイッチ端子を筐体の端まで広げた条件 | 502.2mm | −102.2mm | −2.2mm |
| CRS804・スイッチ端子を筐体の端まで広げた条件 | 401.7mm | −1.7mm | 98.3mm |

厳しい条件の比較は、スイッチ端子の横位置と高さを筐体の左右端・上下端まで広げたものです。Sparkの端子位置は仮定のままで、実機の寸法公差や端子の突出まで検証した値ではありません。

残りが負になる条件は、予約込みの必要長が公称長を超えることを意味します。引き出しや曲げ半径が大きいほど必要長も増えます。たとえば段間隔160mmのリングで、引き出し50mm・曲げ半径30mmとすると最長必要長は364.2mm、40cmの残りは35.8mmです。端子位置とケーブルの型番を確認するまで、この案を実物の配線が届く設計として確定しません。40cmケーブルのスイッチでの電気的な適合も、形状検査とは別に未確認です。

## 検査は配置の計算と参照形状まで

Pythonの検査では円弧の経路長、前後差の影響、曲げ半径を保てない経路の除外、4台の8端子の重複しないリング配線、4つのスイッチ端子への割当、収容範囲、機器と支持範囲の干渉を確認します。参照モデルは形状の妥当性と保存後の再読込を検査します。画面の計算値はPythonの初期案と照合し、条件変更と狭い画面の表示も確認します。

線径、ケーブル同士の干渉、余長の収納、コネクターと取付金具、ケースの実形状と配線・取り外しの操作空間、電源アダプター、通風、実物の耐荷重は今回の検査対象に含みません。これらは配置の実測値を反映してから設計します。ファンの枠・保持板・ガードの収容範囲は干渉検査に含めています。
