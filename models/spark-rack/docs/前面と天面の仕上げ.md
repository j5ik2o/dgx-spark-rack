# 前面と天面の隙間を、ファン格子と同じ縦溝の板で閉じる

上部専用段の案に残っていた見た目の課題を直しました。最上段のスイッチの前の開口、開いた天面、最下段の左右の開口を閉じ、Comet Proの画面を前面板の窓のすぐ後ろへ出しました。板の溝は、前面の140mmファンの格子と同じ10mm間隔、幅7.5mmにそろえています。

既定の中央配置は変えていません。この板は上部専用段と中段の機器棚を持つ案だけに加え、`mise run upper-bay:spark-rack`で生成します。造形用のファイルは生成しません。

`build/`はGit管理の対象外です。以下のリンクは作業環境での閲覧用で、新しい環境では後述のコマンドで再生成します。

[形状候補の画面](../../../build/spark-rack/upper-switch-bay/20261012-205602-37fb329e/fixed-rack.html)と[検査結果](../../../build/spark-rack/upper-switch-bay/20261012-205602-37fb329e/validation.json)を保存しました。

## 4か所の直し方

| 場所 | 直し方 | 見え方の変化 |
|---|---|---|
| 最上段の前面 | 幅184・120・184mmの縦溝の板3枚。上枠の下へ受け板を差し込み、上向きのねじで吊る | スイッチの箱が見えなくなり、中段の板と割り付けがそろう |
| 天面 | 溝付きの天板6枚を枠の上へ載せる。裏の縁を枠の内側へ入れて位置を決める | 上から見てスイッチが見えなくなる。全高は4mm増えて622mm |
| 最下段の左右 | 幅63.7mmの縦溝の板。下端の受け板を電源の床へ留める | 向こう側が見える開口がなくなる。板は前面から約50mm奥 |
| Comet Proの画面 | 厚さ4mmの載せ台を棚から前へ延ばし、Comet Proを前面板のすぐ後ろへ出す | 画面の奥まりが約31mmから4.3mmになる |

最上段の前面の板は外せる形にしました。スイッチの電源とファンがラック前側の面にあるかが未確認のためです。前面の板を外せば、スイッチ前側の作業空間が空くことを検査しています。

天板の溝は、最大134Wのスイッチの上で自然に上がる空気を逃がすためです。スイッチの吸排気方向が分かったら、溝の範囲と天板の要否を見直します。

天板の通気範囲は、寸法定義の`lid_slot_length`を使います。既定の長さ70mmでは、継ぎ目を挟んだ前後の領域へそれぞれ2列を置き、列の間を16mm空けます。ハニカムも同じ範囲へ開けます。寸法を変えると通気範囲が連動し、天板の開口率が15%以上あることを検査します。

## 下の左右の板は、扉の開く範囲を避けて奥へ置いた

制御器の扉は左端を軸に前へ90度開きます。扉の左側の開口を前面の位置で閉じると、開く途中の扉に当たります。そこで左右の板を扉の後ろ（前面から約50mm奥）へ置きました。左右とも同じ奥行にそろえています。

前面へそろえるには、扉を下端の軸で前へ倒す形に変える必要があります。扉の開き方は既に検査と表示を作り込んであるため、今回は変えていません。前面へそろえたい場合は、扉の軸の変更を別の作業として検討します。

同じ理由で、次の2案も採っていません。

- 上段ファンを受ける横梁を動かす案。Comet Proは載せ台で前へ出せたため不要になった。
- 上枠の断面を薄くして、天板を枠の上面へ埋める案。枠の分割と受けの寸法に広く影響するため。

## 部品数は83から95になる

前面の板3部品、天板6部品、下の左右の板2部品、Comet Proの載せ台1部品を加え、印刷候補は95部品になりました。参考形状は65個のままです。

| 部品 | 形状体積の増加 |
|---|---:|
| 天板6枚 | 0.747リットル |
| 最上段の前面の板3枚 | 0.086リットル |
| 最下段の左右の板2枚 | 0.049リットル |
| Comet Proの載せ台 | 0.032リットル |

この体積は、天板の溝長を寸法定義へ連動させる前の生成記録です。その時点では形状体積が14.381リットルから15.295リットルへ増え、中央配置の10.636リットルの約1.44倍でした。現在の体積は各実行の検査結果を参照してください。充填率、支持材、印刷損失を含む材料使用量ではありません。

## 検査した範囲

これまでの検査に、次を加えました。

- 新しい11部品と載せ台が閉じた単一形状で、最大246mmの外形に収まること
- 前面の板が上枠の下面に当たり、前へ引いて外せること
- 天板が上枠と側枠の上面に載ること、溝で天板の面の15%以上が開くこと
- 下の左右の板が電源の床に載り、扉の開く範囲に入らないこと
- 外せる前面の板を除いて、スイッチ前側の作業空間が空いていること
- Comet Proが載せ台に載り、中央の前面板を外して前へ引き出せること
- 天板の厚さを含めた高さで、全部品が枠の外へ出ないこと

これらはCAD上の確認です。溝による風量と騒音、板の固定の強さ、実物の見え方は確かめていません。

## 判断を変える未確定値

- スイッチの吸排気方向と、電源とファンの面。天板の溝と最上段の前面の板の形を見直す。
- 下の左右の板を前面へそろえたいか。そろえる場合は扉の軸を変える。
- PAHT-CFの黒で印刷したときの溝の見え方と、反りや収縮。
