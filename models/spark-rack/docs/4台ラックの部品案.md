# 共通枠・通気トレー・140mm保持部を部品として確認する

**この136部品案は不採用です。印刷しません。** 対象は2026年10月9日17:21の生成で、[生成物を保全](../../../archive/spark-rack-structure-rejected-20261009-172152/README.md)しています。現在の入口と条件は[凹凸の接合試験片と次案](凹凸の接合試験片と次案.md)を参照してください。以下は旧案の構造・金具・印刷向きを残す履歴です。`structure:spark-rack`は接合試験片のみの生成へ変更しました。

4台専用ラックの構成を、ボルト穴と接続金具を持つ部品案へ具体化しました。28mm角の柱と梁で共通枠を作り、Spark各台を通気トレーで支え、140mmファンは取り外せる保持部へ固定します。リング用とスイッチ用では同じ部品を使い、上段の支持位置を60mm移動します。

これは全体を樹脂部品で作る第一案です。部品数は136個と多く、実物の強度・適合は未検証です。まず接続金具と短い角材を試作し、全体の部品数や金具を減らす余地も評価します。初回は生成方法と構造の説明を読み、部品表と金具は必要なときに参照してください。

## 生成して組立図と個別部品を開く

FreeCADの実行環境で、リポジトリのルートから実行します。

```sh
mise trust
mise run structure:spark-rack
```

出力は `build/spark-rack/four-node-structure/<実行ID>/`。実行ごとに新しいフォルダへ保存します。`four-node-structure.html`で配置方式と機器表示を切り替えられます。`four-node-structure-ring.FCStd`で当面のリング用、`four-node-structure-crs812.FCStd`または`crs804.FCStd`で将来の配置をFreeCADで確認できます。

各部品の立体データは`stl/`、交換用の立体データは`parts/`、組立図は各方式の画像にあります。部品数と金具は`structure-report.json`、形状・干渉・締結経路は`validation.json`、保存後の再読込は`assembly-validation.json`、生成元と出力の内容照合は`manifest.json`を参照してください。

FreeCADの実行入口は[run_four_node_structure.FCMacro](../source/run_four_node_structure.FCMacro)です。部品案の寸法は[four_node_structure_parameters.py](../source/four_node_structure_parameters.py)、形状は[freecad_four_node_structure.py](../source/freecad_four_node_structure.py)、生成は[build_four_node_structure.py](../source/build_four_node_structure.py)で管理します。

従来の本体ラックの正本は保持しています。今回の部品案は採用前の別入口で生成し、通常の`build:spark-rack`と3MF生成タスクは従来モデル用です。本番素材・条件を決める前に、本番用の印刷設定として扱いません。

## 重さはトレー・梁・柱・脚へ伝える想定

共通枠の部材外形は幅520×奥行530×高さ420mmです。制御ケース、脚、接続金具を含む占有範囲は幅618×奥行542.6×高さ428mmです。旧仮配置より幅が増えるのは、制御ケースを側梁の外へ置いて、梁との重なりを解消したためです。

四隅の柱は105mm・222mm・93mmの3部材で構成します。横梁は250mmと214mm、奥行梁は190mm・142mm・142mmへ分割します。これは造形のための部品分割で、1台用ラックを増設する連結構造ではありません。接続部分は56mm長の金具とボルトで固定します。

柱と梁の継ぎ目は、本体支持段や将来の中央支持段と重ならない位置へ置きました。枠の下には着座式の脚を4個置き、接続金具の下面が設置面へ先に当たる状態を避けます。脚は接着・締結を実証したものではなく、枠を載せて位置を確認する試作部品です。

## 本体の支持段は2つの位置を共用する

下段の本体底は設計座標の高さ72mmです。上段はリング用232mm、スイッチ用292mmで、中心間隔は160mmまたは220mmです。脚の下面は設計座標の−8mmなので、設置面からの実高さはそれぞれ8mm高くなります。

各段は側梁2本と横梁2本で構成します。横梁の位置は、本体前端から12mm内側と後端から12mm内側です。トレーは横梁へ載せ、中央の2本の皿ねじで横ずれを留めます。ねじだけで本体荷重を吊るす構造ではありません。

トレーの外形は158×156mm、支持板厚8mmです。4つの通気開口を設け、外周と中央の十字を支持面として残しています。左右と前面には高さ3mmの位置止めを置き、本体外形に対して約2mmの横余裕を仮定しています。足の接触位置と底面通気口は実測後に支持面へ反映します。

上段を移す場合は機器と配線を外し、支持段の側梁・横梁・トレー・ファン保持部・制御ケース取付部を上の位置へ移します。新しいラックを積み重ねる方式ではありません。中央のスイッチ支持板は、柱の取付穴位置の予約までで、支持板とその耐荷重は今回の部品案に含めていません。

## ファン保持部は2本の腕で支持梁へ固定する

本体用は140mmを4個、取付穴の中心間隔124.5mmを基準とします。保持板は幅176×高さ152×厚さ4mm、送風開口は直径132mmです。ファン外形より外側の2本の腕を、支持梁の前面へ固定します。ファンの後端とSparkの前面の間隔は25mmです。

腕には締結部へ工具を入れるための開口を設けました。保持部の固定は左右の2本のねじ、ファンとガードは別の4か所で留めます。保持部を前方へ取り外す想定で、実物のガード・つまみ・工具で操作できるかを試作します。120mmの2個は別置きの電源アダプター用として維持します。

制御ケースには既存の共通ドックを使います。新しい取付板に、共通定義どおり28mm間隔の穴とM4ナットの座を設けました。台座の3mmの突出を含めて接触面を合わせ、支持梁の締結穴とねじ先端の逃げ穴も検査しています。ケース本体は収容範囲の参照形状で、開口ごとの操作空間はまだ確認していません。

M4の必要数は計288本です。M4ナットは各締結に合わせて用意し、柱の四隅と制御ケース取付板では印刷したナット座へ先に入れます。平座金は頭部とナットの座面に合わせて選びます。この一覧は設計上の長さで、購入済み金具の流用や締付けを実証した記録ではありません。トレーの皿頭は外径8.5mm以下、ナット座はM4対辺7mmに対して対辺7.3mmを初期値とします。

## 接続部分を先に試す

`joint_fit_stub.stl`を2個、`splice.stl`を1個印刷し、M4×45とナット4組で接続します。片側隙間0.3mmの差し込み、ねじ穴、締付け時の割れや緩みを確認します。続いてトレー1個とファン保持部1個を作り、本体の足・ファン・ガード・金具・工具の実物に合わせます。

今回の検査は、閉じた単一部品、立体データの閉じた形状、造形外形、3配置の部品間干渉、参照機器との干渉、288本の締結軸、保存後の再読込です。実際の金具の全外形、ねじ同士の干渉、ナットの入れ方、材料の強度、長期荷重、振動、冷却は別に検証します。困った箇所は部品名、生成実行ID、素材、金具寸法とともにこの設計の会話へ記録してください。

用語：共通枠は4台全体を支える柱と梁、支持段は機器を載せる梁とトレー、保持部はファンを固定する前面部品、接続金具は造形のために分割した部材を固定する部品です。
