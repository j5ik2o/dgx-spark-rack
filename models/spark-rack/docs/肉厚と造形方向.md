# 肉厚と部品別の造形方向

本体を骨格にする案の、2026年10月19日の検討です。ラック・栓69個に、制御器ケースの本体6個と蓋6個を加えた81個へ、単品の造形姿勢を設定します。組立時の位置とファンの正立固定は変えません。造形用の形状ファイルや印刷設定はまだ生成しません。

## 細い角栓と、寝かせたときに浮く部分を修正する

以前の候補には、電源ファンの接合で断面が0.99mm角になる角栓が1本ありました。ファン支持腕と取付板が接する面の重なりを4mmから8mmへ広げ、角栓の中央断面を全20本で1.8mm角以上とします。角栓穴の周囲には、ほぞの指定断面で1mm以上の肉を残します。受け面で荷重を受ける方針は維持します。

角栓のつまみは幅10mm・引出し方向の長さ6mmを維持し、軸とつまみの片面をそろえます。軸と、8mmずらしたつまみの曲がりを層の面内へ置き、全長を造形台へ接地させるためです。本体間の上下の隙間は14mmから20mmへ広げます。高さは6mm増え、上段本体の底面は130.5mmになります。配線経路と余長予約も、この変更に合わせて再検査します。

ファン用割りピンも、軸を寝かせて全長を接地できる平面を設けます。軸の直径3.6mm、割れ目の幅0.9mm、返しの外径5.4mmは維持します。二股を始める位置を軸の先端から5mm手前から12mm手前へ延ばし、切り込みの根元を半径0.45mmで丸めます。軸と二股がたわむ方向を層の面内へ置く候補です。材料に必要な変形量と寿命が適合することは未確認です。

## 指定断面の寸法

| 部位 | 寸法と検査の範囲 |
|---|---|
| 本体の外側へ出るコーナー接続部 | 基準寸法8mm。切欠きや接合穴を含む全箇所の最小肉厚ではない |
| ファンの取付板・外周 | 板4mm・外周の張出し4mm |
| ファンの長い腕 | 8×8mm。特に背面の長い腕の曲げと長期荷重は未確認 |
| 機器の受け板 | 基準4mm。支点間のたわみは別途確認 |
| 角栓の中央断面 | 全20本で1.8mm角以上。実際の形状を薄い検査箱で切って測る |
| ほぞの角栓穴の周囲 | ほぞの法線方向と、栓に直交するもう一方向で、両側に1mm以上。実際の指定断面に材料があることを確認 |
| ファン用割りピン | 二股の中央断面の片側は1.35mm、頭は1.6mm。薄肉の例外として実物試験が必要 |
| 制御器ケース | 壁・底・蓋は各2mm。基板押さえは3mm、支柱の基準断面は6×4mm |
| 制御器の受け台 | 底板8mm。ケース周囲の低い壁など、全箇所が8mmではない |

この表は指定断面と基準寸法の確認です。形状全体の最小肉厚を自動測定した結果でも、各部の強度の合格値でもありません。角栓穴の片側の遊び0.08mm、ほぞの片側の遊び0.15mmは参考値です。本番素材の収縮と実際の造形方向で照合します。

## 造形方向の候補

| 部品 | 置き方 | 支持材と残る確認 |
|---|---|---|
| 本体を受ける接続部と一体の機器受け | 組立時の上下方向を層の面内へ置く。前後方向の候補から精密面に支持が掛かりにくい向きを選ぶ | 一体化した受け・腕・制御器受け台の張出しに支持が必要。受け面と差込口を避け、支持材を取り出せるか確認 |
| 前後のファン保持部 | 側辺を下にし、長い腕を層の面内へ置く | 反対側の腕と枠の張出しに支持が必要。穴、ほぞ、角栓の通路を避ける |
| 左右の電源ファンの取付板 | 板を平置きする | 取付穴を造形台へ垂直にする。接合口の橋渡しを確認 |
| 角栓 | 軸とつまみの平面を下にし、軸と曲がりを寝かせる | 支持材不要の候補。実際の押出し経路は未確認 |
| ファン用割りピン | 切り欠いた平面を下にし、軸と二股のたわむ方向を寝かせる | 支持材不要の候補。半円部、返し、細い二股の経路を確認 |
| スイッチの支持レール・余長受け | 主な板を平置きする | 側方の腕と抜け止めの下を確認 |
| 制御器ケースの本体 | 底面を下にする | 配線開口の橋渡しを確認 |
| 制御器ケースの蓋 | 天面を下にし、蓋と一体の基板押さえを上へ造形する | 押さえの張出しと支持材の除去を確認 |

積層式の造形には方向による性質の違いがあり、支持材に接する面は仕上がりも変わります。薄い形状は押出し幅にも制約を受けます。[Prusaの設計指針](https://help.prusa3d.com/article/modeling-with-3d-printing-in-mind_164135)を一般的な参考にしています。ここで選んだ寸法・向きは今回の設計判断であり、その資料が本ラックや本番素材の強度を保証するものではありません。

## 検査とブラウザ表示

[body_frame_print_plan.py](../source/body_frame_print_plan.py)で、81個へ造形姿勢を設定します。反転や拡大縮小を含まない変換で単品を接地し、造形面に平面があること、角栓と割りピンは全長にわたって平面が届くことを確認します。曲面を切り欠いた部品は、元の円柱の外形が残る通常の外形箱ではなく、切断後の形状の外形を使います。

造形台の候補範囲は246mm、外周の接着を助ける帯は5mmです。各部品の平面寸法へ帯の幅を両側に加えたものと、部品の高さが範囲へ入ることを確認します。同一プレートへの部品の詰め合わせは含みません。

ブラウザの「部品の造形方向を見る」で、全81個を切り替えられます。灰色の面が造形台で、画面内の上方向へ積層する姿勢です。`print-plan.json`には変換、寸法、接地する平面の面積、指定断面の検査結果と支持材の確認事項を保存します。[支持材の配置と除去](支持材の配置と除去.md)では、支持材を置く領域と除去経路までを別に検査します。格子・枝などの実際の支持構造や押出し経路は生成していません。

## 本番の印刷条件と実物試験は残す

本番はユーザー指定の黒の炭素繊維入り耐熱ナイロン PAHT-CF、仮組みはポリ乳酸です。[素材の記録](../../../print-projects/README.md)を引き継ぎます。本番のノズル、積層の厚さ、外周の数、充填率、乾燥と収縮の条件は未設定です。既存の試作用設定を本番へ代用しません。

支持材を配置して取り出せるかの確認、スライサーでの経路確認、本番素材での適合・弾性・繰り返し操作・曲げ・長期荷重の確認が残ります。現在の出力は参考形状と検討結果であり、本番の造形用出力は停止したままです。
