# 左右の構造面と共通の前面へ4台ラックを改める

見直しでは、露出した斜材と個別の制御器箱が目立つ構成を、左右の構造面とそろえた操作面へ改めました。本体4台、140mmファン4個、電源用120mmファン2個、既存の制御器ケース6組を維持します。最終接続は[CRS812と2m分岐ケーブル](最終接続構成.md)です。

「Appleが設計するとしたら」という問いには、外観、支持構造、操作、交換、組立を一つの方針で整理できているかを基準にしました。Appleの実際の設計方針を断定するものではありません。現在の案では形状を具体化しましたが、組立機構と実物の検証が残っています。

## 面が荷重を受け、支持梁を棚と床へ統合する

左右の側面は外側4mmの構造壁と内側のリブで構成します。外側の斜材を廃止し、棚の差込み部と横梁の受けから構造壁へ材料を連続させました。内側には開放したポケットを設け、支持部、ねじ穴、分割境界、側面ファンの座を全厚で残します。薄い面で覆っただけの構成にはしていません。

独立していた支持梁30部品を、本体の固定棚6部品と電源支持床6部品へ統合しました。可動トレー8個は引き続き機器ごとに取り出す候補です。電源床は上面8mmと下向きのリブを組み合わせ、トレー縁の直下に連続した支持帯を置きます。内側に密閉した空洞はありません。

前案の印刷候補88部品に対し、現在は72部品です。既存ケースと購入品の参考形状は含みません。ヒンジ、留め具、脚などが加わるため、製造時の部品数は未確定です。見直し前の形状体積12.115リットルに対し、現在は10.636リットルで約12.2%減りました。比較元は`build/spark-rack/fixed-rack/20261012-013332-81044883/validation.json`、見直し後は`20261012-021353-f2b5f35b/validation.json`です。形状体積は充填率や支持材を含む印刷材料量とは区別します。

## ファンと制御器の前面をそろえる

上下の140mmファン保持板と、制御器の共通面を奥行位置−336.67mmへそろえました。前面を上下のファンと下部の操作面として読める構成です。ファン保持板の張り出す持ち手は廃止し、下縁に浅い指掛かりを置きました。

制御器の共通面は既存蓋の前面と同じ位置です。面を蓋より前へ追加せず、つまみの露出2.83mmを維持します。蓋全体が見える開口を設け、個々の蓋とねじへアクセスできる形にしました。6組のケースと共通ドックは再利用します。共通面のねじは背面から締める候補です。

前面と側面のファン保持板には、幅2.5mmの一体格子を設けました。円形開口の約25%を格子が塞ぐため、格子の隙間、指の入り方、風量、騒音、たわみは実物で確認します。面積の減少率を、そのまま風量の減少率とは扱いません。仮の指径24mm、表示の視線、蓋ねじへの工具経路を形状上で検査しますが、使いやすさの実測値ではありません。

## 接続方式が変わっても段位置を維持する

| 対象 | 形状候補の基準 |
|---|---|
| 共通枠 | 幅544×奥行460×高さ560mm。脚を含まない |
| 下段と上段の本体底面 | 高さ208mmと428mm |
| 段間隔 | 220mm固定 |
| 左右の本体中心間隔 | 180mm |
| 本体前方 | ファン後端まで155.67mm。必要な100mmを確保 |
| 電源 | 下部へ4個を2列×2列で平置き。底面は高さ40mm |
| 電源と本体の仕切り | 高さ152〜156mmの水平な板 |
| 制御器 | 共通の前面へ2列×3段 |
| 最終スイッチの参考位置 | 接続端子面を本体背面から100mm後ろへ置く |

前方100mm、左右20mm、後方400mmの空間は[NVIDIAの公式設置資料・6ページ](https://www.nvidia.com/content/dam/en-zz/Solutions/dgx-spark/DGX-Spark-Quick-Start-Guide.pdf#page=6)を基準に予約します。枠後端は本体背面から110mmなので、枠の外にも壁との距離が必要です。枠前端から後方400mmの空間の端までは750mmです。交換作業の空間は別に確保します。

## 機器の交換方向を部品ごとに固定する

本体とスイッチは接続を外して背面へ、140mmファンは前面へ、120mmファンは保持板ごと側面へ取り出します。側面の開口は126mm角で角を丸め、120mm角のファン本体が通る形です。144mm角の保持板は外面の深さ4mmの座へ収めます。

前側の電源2個は制御器扉を開いて前へ、後側2個は背面へ取り出します。制御器6組と共通面を載せる扉は左端を軸に前方へ90度開く候補です。開く予約は枠前端から約309mm前へ広がります。ヒンジ、留め具、接続線の余裕は未設計です。

本体トレーの足と吸気口に対応する支持部、ガイド、抜け止めは未完成です。スイッチは外形と支持梁までを配置し、耳込み幅、奥行、質量、支持面を確認して支持板を設計します。

左右の構造面は各6枚へ分割します。最大外形は28×242×244mmで、246mmの造形範囲へ収めます。分割線の24mmの重ね継ぎは交差点で厚さを4層へ分けます。棚と床にも重ね継ぎとねじ穴を設け、部品間の体積重なりと支持面の接触を検査します。全体へ組み込む連続した経路、積層方向、長期荷重、横揺れは別に確認します。

## 余長収納は実ケーブルで確定する

本体の下段とスイッチの間に、左右各220×290×24mmの収納予約を置きます。2m分岐ケーブル2本を想定し、排気、機器の取り出し、端子解除を妨げない保持部へ具体化するための空間です。余長が収まることは未検証です。

最終ケーブルの暫定曲げ半径は42mm以上ですが、主線と分岐線の長さ、分岐部と端子の外形、公称長の測定基準は未確定です。リング用40cmケーブルの曲げ条件は別に確認します。

## 正本から再生成して検査する

```sh
mise trust
mise run redesign:spark-rack
```

`build/spark-rack/fixed-rack/<実行ID>/`へ、FreeCADの参考形状、形状交換ファイル、回転できる表示画面、配置、支持構造、操作面、検査結果、入力と生成物の照合記録を保存します。既存の生成物を上書きしません。固定機構と実測値が未確定のため、造形用のファイルは生成しません。試験片の印刷を後回しにする指定も維持します。

寸法の正本は[spark_rack_parameters.pyのFixedRackParameters](../source/spark_rack_parameters.py)、形状の入口は[freecad_spark_rack.pyのcreate_fixed_rack](../source/freecad_spark_rack.py)です。配置は[fixed_rack_layout.py](../source/fixed_rack_layout.py)、形状演算は[fixed_rack_geometry.py](../source/fixed_rack_geometry.py)、支持構造は[integrated_rack_supports.py](../source/integrated_rack_supports.py)、共通操作面は[controller_front_face.py](../source/controller_front_face.py)、検査は[validate_fixed_rack.py](../source/validate_fixed_rack.py)へ分けます。

検査では、閉じた単一形状、最大246mmの外形、静止干渉、交換予約、前後の空間、支持面の接触、操作面の仮空間、保存後の再読込を確認します。交換予約の手の余裕12mmは設計仮定です。実端子、ケーブル、指と工具による交換操作を確認した値ではありません。

## 次は固定機構を完成させる

この形状を続ける場合は、全体組立、制御器扉のヒンジと留め具、トレーのガイドと抜け止め、ファン保持部の留め具、仕切りの固定、スイッチ支持板、余長収納、脚を具体化することを推奨します。接合面を保護した外周の面取りと丸みも、この段階で適用します。

実測が必要な箇所は[未確定値の記録](../reference/pending-mount-measurements.json)へ残します。寸法と固定機構を反映した後に、接合、耐荷重、材料、温度、処理性能、騒音、実物の交換を確認します。これらが未確認の間は完成設計として扱いません。
