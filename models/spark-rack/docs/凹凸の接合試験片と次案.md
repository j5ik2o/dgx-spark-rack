# 枠を小型化し、本体と電源を一つの枠へ収める

2026年10月9日17:21の136部品案は不採用です。4台の共通枠、140mmファン4個、既存の共通ドック、電源用120mmファン2個を維持し、部材の端の凹凸へ継ぎ方を改めます。[指定生成物は保全済み](../../../archive/spark-rack-structure-rejected-20261009-172152/README.md)です。旧案の金具一覧と横梁の印刷向きは履歴として残します。

今回造形用に出力するのは短い接合試験片5種類だけです。全体の72個案、ファン保持部、トレー、スイッチ支持板の造形データは作りません。

2026年10月9日のユーザー指定で、試験片の印刷は後回しにします。現物の適合、段差の当たり、ガタは未確認のままです。その間は部材の凹凸と全体の組立順を図面上で検討し、実測が必要な梁の取付穴とスイッチ支持板は保留します。印刷を再開するときは短い試験片から確認します。

## 設計変更後の全体像を見る

```sh
mise run overview:spark-rack
```

`build/spark-rack/candidate-overview/<実行ID>/rack-candidate-overview.html`に全体構想図を生成します。リング接続、CRS812、CRS804の配置を切り替え、斜め・前面・背面・側面・上面から確認できます。斜め表示はドラッグで回転します。

柱と梁は別部品の継ぎ手を取り除いた外形で示し、造形分割の候補線を残しています。角と直線部の接合は、検査済みの短い形状の拡大図を添えました。全長部材への凹凸の統合、全体の組立経路、梁の取付穴、スイッチ支持板は未完成です。この図から造形用ファイルは生成しません。

最新のユーザー指定は、両スイッチの収容を検討しながら余白を詰め、ACアダプターも枠内へ収めることです。共通枠を512×520×420mm、柱の間の幅を456mm、奥行を464mmへ変更しました。枠の短縮は幅8mm・奥行10mmですが、制御ケース6個を内側へ移すため設置幅は618mmから512mmになります。脚は底面から8mm下に示します。リング用の段間隔160mmとスイッチ用220mmは維持します。

電源は既存の正本にある約99×99×35mmを使い、手前下側に2列×2段で仮配置します。ACとUSB-Cの出口を前後へ向け、端子側に各30mmの設計予約を置きます。120mmファン2個は左右に置き、側面へ排気する構想です。電源と本体の間には参考の仕切りを示し、電源の温風を本体の吸気へ直接向けないようにします。支持部の接合、端子の実形状、冷却効果は未確認です。

旧全体構想も比較用に保持し、画面の「案」で切り替えられます。3配置とも機器と枠の外形箱、仮外径10mmの配線経路、電源端子側30mmの予約に干渉がないことを確認しました。ファンの穴や接合形状を含む全体検査ではありません。

生成元は[build_rack_candidate_overview.py](../source/build_rack_candidate_overview.py)と[rack_candidate_overview.html](../source/rack_candidate_overview.html)です。不採用の全体案の形状コードは読み込みません。接合図として参照した試験片の生成記録も、同じ実行の照合記録へ含めます。

全体図の再生成に過去の`build/`は不要です。接合部の参照図は[reference内の保全図](../reference/joint-illustrations-20261009/README.md)、前の案は[archive内の比較データ](../../../archive/spark-rack-overview-20261009-200723/README.md)から明示的に読み込みます。それぞれ元の生成記録と保全時の内容照合記録を添えました。現在の配置はPythonから生成し、比較データを現在の部材の形状として採用しません。

## 柱と梁は段差で受け、ほぞを浮かせる

試験片の外形は28mm角です。梁の根元に8mmの段差を設け、柱の水平な受け面に載せます。奥のほぞは差し込み12mm、幅12mm。この根元とほぞの寸法は固定形状で、調整できる設定には含めません。片側隙間は0.3mmとし、ほぞの下面は受け穴の底から浮かせています。

隣り合う2本の梁の根元は、角の内側を相補的に逃がします。奥のほぞは高さを分け、低いほぞの梁を先に、次に高いほぞの梁を上から入れます。逆の順番では途中でほぞが重なるため、この順序を試験片に明記しました。上側の柱は梁の後に取り付ける構想です。

直線部は二股の端に上へ開いた溝を設け、相手の差し込みを上から落とします。二股の底面で差し込みの下面を受けます。別部品の差し込み金具や外板は使いません。

この試験で確認するのは、受け面の当たり、ほぞや二股のガタ、組み入れる順序です。全体の柱分割位置、リング用とスイッチ用の高さ切替、全体を組み立てる経路、止めねじは未設計です。止める場合は内側か下面のねじ1本に限定し、外へ固定板を追加しません。

## 接合試験片だけを生成する

```sh
mise trust
mise run joint:spark-rack
```

`mise run structure:spark-rack`も現在は同じ試験片だけを生成します。出力先は`build/spark-rack/joint-coupons/<実行ID>/`です。毎回新しいフォルダを作り、既存ファイルを上書きしません。実際のスライスとプリンターへの送信は行いません。

| 造形用ファイル | 数量 | 確認する部分 |
|---|---:|---|
| `column_socket.stl` | 1 | 柱の受け穴と水平な段差 |
| `beam_lower_tenon.stl` | 1 | 先に入れる低いほぞの梁 |
| `beam_upper_tenon.stl` | 1 | 後から入れる高いほぞの梁 |
| `beam_fork.stl` | 1 | 直線部の二股と底面 |
| `beam_drop_blade.stl` | 1 | 二股へ上から入れる差し込み |

差し込み側の梁3種類は、太い端面を造形面へ向けています。短い形状の適合確認用の向きで、全長部材の向きが決まった後は、その向きでも再確認します。材料、収縮、造形面の状態による隙間の変化は実物で確認します。

`joint-coupons.FCStd`と`corner-coupons.step`は接合状態の確認用です。`validation.json`には受け面の面積、干渉、上からの挿入経路と順序を記録します。`stl-validation.json`と`manifest.json`で閉じた形状と、入力・生成物の内容一致も確認できます。

## 72個は電源を内蔵する前の数量目標

旧案の別部品の接続金具32個、角の固定板24個、横梁受け8個を廃止する方針です。柱・梁52個と、トレー、ファン保持部、脚、制御ケース取付部、共通ドック各4個の72個は、電源を内蔵する前の数量目標です。最新案では電源支持部、120mmファン保持部、電源用ドック、仕切りが加わるため、部品数は未確定です。参考外形の数を印刷部品数として扱いません。

未測定の30mm横ずれを梁のファン・トレー取付穴へ固定しません。[未確定値の記録](../reference/pending-mount-measurements.json)に、端子、足、採用する横ずれ、ケーブル条件、スイッチの耳込み幅と奥行を記録する欄を設けました。必要な値が空の間は、製造用の梁穴とスイッチ支持板を生成しない方針です。

CRS812の資料上の本体幅443mmは、耳込み幅ではありません。耳が482.6mmまで伸びる場合、最新案の内のり456mmには入りません。筐体を下から支え、取付耳を外す構想ですが、耳と支持方法が確定するまで支持板を生成しません。奥行268mmと156mmの食い違いも残しています。163.25mmの旧予約穴は次案に使いません。CRS804の公式寸法図は再確認し、筐体奥行360mmと後部の突出を含む387mmを区別しました。収容奥行387mmは維持します。

## 下段高さと制御ケース位置は共通の定義へそろえる

[rack_candidate_datums.py](../source/rack_candidate_datums.py)を次案の共通基準にしました。下段底の設計座標は72mm、本体用制御ケースは側梁の内側へそろえます。配置参考の横ずれは0mmを初期表示とし、端子の30mm偏りは配線評価用の未測定の仮定として残します。採用する取付位置は実測後に決めます。

不採用の136部品案のコードは`archive/spark-rack-structure-rejected-20261009-172152/source/`へ移し、履歴のために保持します。その再生成は明示的な履歴用実行だけに限定し、出力も`archive/build-history/`へ分けます。既存の136個を印刷しません。

## 導風は形状の参考として追加する

`air-guide-preview.FCStd`に、ファン後端の円形開口から本体前面の参考外形へ風を寄せる形状を置きました。入口径132mm、出口の参考内寸154×54.5mm、移行部分は23mmです。140mmファンと124.5mmの取付穴間隔は維持します。

本体前面の通気口は未測定です。この形状は保持部との一体化、取付、風向、圧力損失、冷却を検証したものではなく、造形用ファイルに含めていません。出口を実際の通気口へ合わせてから保持部へ統合します。

用語：段差は梁の重さを受ける水平な面、ほぞは奥へ入る位置決めの突起、二股は相手の差し込みを両側から案内する部材の端です。試作で合わない場合は、試験片名、材料、生成実行ID、段差の当たりとガタの測定値をこの会話へ記録してください。
