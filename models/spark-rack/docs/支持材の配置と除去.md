# 支持材を置く領域と外す順序

現在の部品分割を維持して、支持材の配置と除去を検討した参考案です。対象はラック・栓69個と、制御器ケースの本体・蓋12個です。本体を受ける部品の造形方向を調整し、支持材の領域と、小分けにほぐした後の除去経路を形状で確認します。

表示する橙色の体積は、支持材を置く領域の候補です。実際の格子・枝・接触層・印刷経路ではありません。支持材の密度、界面と材料、本番の印刷条件は未設定です。造形用の形状ファイルや印刷設定は生成しません。

## 部品を分けず、精密面へ支持材が掛かりにくい向きを選ぶ

本体を受ける接続部と、一体化した機器受けは、上下の荷重が通る方向を層の面内へ置く方針を保ちます。前後方向に寝かせる候補の中から、機器に向く広い面が支持材の接触する下面になりにくい向きを選びます。その条件が同じなら、造形台へ接する平面が広い向きを選びます。

前後ファンの保持部は側辺を下にする案を維持します。反対側の長い腕の下には、もう一方の腕との間に支持材が入ります。支持材を一塊にせず、長さを抑えた領域へ分け、開放された側から引き出します。大きなファン開口内にも、曲面の上部を支える領域を予約します。開口の内側に収め、開口に垂直な向きなどへ、分けて引き抜く経路を確認します。

角栓と割りピンは全長を接地する平面を維持し、今回の支持材領域は設定しません。細い半円部、返し、割れ目の実際の経路はスライサーで確認します。

## 接触面と穴を保護する

| 対象 | 支持材の扱い |
|---|---|
| Spark、電源、周辺機器に向く面 | 機器の参考外形に0.6mmの余裕を加え、支持材の上端と下端を接触させる面を避ける |
| ほぞと受け穴 | 接合部とその周囲へ支持材の領域を入れない |
| 角栓の通路 | 栓の参考外形に余裕を加えた範囲へ入れない |
| ファンの取付穴 | 穴の周囲と軸方向を保護し、領域を入れない |
| 制御器ケースの端子口や精密面 | 支持禁止箇所を残し、橋渡しの線と張出しをスライサーで確認する |

支持材の上端だけでなく、部品上から支持材を立ち上げる場合の下端も検査します。機器を後から搭載する空間は、接触面を傷めず除去できる候補に限り、支持材が一時的に通過できます。機器を載せる前に支持材を除去する手順です。

支持禁止箇所に隣接する小穴・開口・薄い張出し、丸みの支持判定は残ります。「支持禁止にした」ことは「支持なしで印刷できる」ことの確認ではありません。実際に橋渡しする線、たれ、穴寸法と表面品質は、スライサーと本番素材で照合します。

## 小分けの領域を作る仮条件

水平な張出しの内側へ、小分けにした領域を置きます。長い方向は36mm以内とし、外周を0.6mm内側へ寄せます。水平な上端の隙間は0.3mm、部品上から立てる場合の下端の隙間も0.3mmとする仮条件です。ファン開口内は半径方向に0.6mmの余裕を取り、開口内の領域も分けます。これらは本番のスライサー設定値を決定したものではありません。

領域を置く場所には、実際の部品の下面があることを確認します。部品上に立てる場合は、下側にも領域全体を受ける平面があることを確認します。領域と部品が体積で重ならないこと、接合口へ入り込まないことも検査します。下側が曲面で領域全体を受ける平面がない場合などは、その箇所に領域を置かず、確認事項として検査結果へ残します。全ての張出しへの支持を確定した結果ではありません。

領域の境界は、支持材を切り離す箇所の候補です。印刷時の支持材へ同じ境界や隙間を作る指示ではありません。細長い支持の安定性、支持材同士のつながり、界面層と接着は実際の支持構造を生成してから確認します。

## 外側から順に引き出す

1. **造形台から外し、部品を支える。** 検査は、部品が造形台に付いた状態ではありません。部品を回したり持ち上げたりして支える操作と、部品の強度は未検証です。
2. **選んだ領域を小分けにほぐす。** 切断・剥離に必要な力と、表面を傷めない操作は実物で確認します。
3. **外側にある領域から引き出す。** 残っている支持材の領域と部品を残し、ペンチ先端の仮外形と一緒に引き出す経路を確認します。
4. **奥の領域を順に外す。** 先に外した領域だけを検査から取り除き、次を外します。部品の外形の外まで出て初めて、除去した扱いにします。
5. **穴と接触面を点検する。** はめ合い面、機器の受け面、端子口の寸法と支持痕を確認します。

ペンチ先端の仮外形は2×3×12mmです。特定の工具の実測値ではなく、柄と手は含みません。ブラウザの緑色の箱がこの先端です。領域と先端を同じ向きに動かし、途中の干渉も検査します。剛体の領域が通るという結果と、実物の支持材を折ったり剥がしたりできることは区別します。

## ブラウザと検査結果

「部品の造形方向を見る」から「支持材の領域と除去手順を見る」を選びます。「支持材の全領域」で配置を確認し、工程を選んで引き出す位置を動かせます。取り外し済みの領域は、次の工程では表示しません。

- [body_frame_support_regions.py](../source/body_frame_support_regions.py)：支持禁止範囲、水平な下面の領域、ファン開口の領域。
- [body_frame_support_removal.py](../source/body_frame_support_removal.py)：工具先端を含む除去順の探索と再検査。
- [body_frame_supports.py](../source/body_frame_supports.py)：全81部品の領域、確認事項、表示用形状をまとめる。
- 各実行の `support-plan.json`：領域、支持禁止範囲、除去経路、スライサーで確認する箇所。
- 各実行の `support-scene.json`：領域の参考形状。造形用の支持材ではない。
