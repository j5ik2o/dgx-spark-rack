# ファンコンケースを両ラックへ取り付ける

温度センサー付き基板型ファンコンを、ファン1個につき1個使用します。140mm×2用と120mm×2用はそれぞれ、ファンコン2個・12V 3A電源1個・DC電源二股ケーブル1本の独立した系統です。ケースも合計4個です。分岐するのはコントローラーへのDC電源で、ファンの制御信号ではありません。基板端子台への接続用DCジャック付きケーブルも、各コントローラーに必要です。

## 取付方式

ラック外面 → 一体スペーサー付き共通ドック → ケース底の外側取付耳、の順に固定します。表示窓とつまみは外側を向きます。ケース底内部にねじ頭を突出させないため、基板下面の部品との隙間を減らしません。ドックには通風用の開口を設けています。

| 項目 | 設計値 |
|---|---|
| ドック外形 | 100×48mm、板厚8mm＋スペーサー3mm |
| ラック側M4穴 | ピッチ28mm、通し穴4.5mm、頭の座ぐり8.4mm径・4.5mm深さ |
| ケース側M3穴 | ピッチ92mm、通し穴3.4mm、耳の表面に90度皿座ぐり（径6.4mm・深さ1.5mm） |
| ケース取付耳 | 厚さ4mm。ケースの外形長さは耳を含め100mm |
| ドック裏面のM3ナット穴 | 対辺5.8mm、深さ2.8mm |

取付規格は [controller_mount.py](../../../tools/cad/controller_mount.py) で共有します。

## 外観

ドックは外周と通風窓をR4、触れる外周稜線をR0.4に丸めます。ケースの取付耳は先端をR3とし、ケース本体の角丸と揃えます。穴位置・穴径・締結部の厚さは変えません。取付耳は薄い飾り板にせず、4mmの厚さを維持します。

外観確認用の組立図では、ラックとケースを黒系、ドックを少し明るいチャコール、ファンをベージュで表示します。実際のファンは決定済みのベージュ／ブラウン、印刷部品は黒を想定しています。CADの表示色はフィラメント設定を変更しません。

## 配置と必要数

| ラック構成 | ファン数 | ケース・ドック数 | 配置 |
|---|---:|---:|---|
| 本体ラック1台 | 1 | 各1 | 左外側 |
| 本体ラック縦2台 | 2 | 各2 | 左外側、各段に1個 |
| 本体ラック横2台 | 2 | 各2 | 左右の外側 |
| 本体ラック4台 | 4 | 各4 | 左右の外側、各段に1個 |
| アダプターラック1台／縦2台 | 1 | 各1 | 左前柱の外側 |
| アダプターラック横2台／4台 | 2 | 各2 | 各列の外側前柱に1個 |

横連結する場合、列間の内側には取り付けません。本体ラックはケース長手を縦向き、アダプターラックは横向きに配置します。コントローラー自身の消費電力、電源極性と基板への配線は実機で確認してください。

## 金具と組立

ケース1個のラック取付に、M4×25六角穴付きボルト2本・M4ナット2個、M3×12の90度皿ねじ2本・M3ナット2個を使います。M3の長さ12mmは頭を含み、頭径6mm以下を想定します。皿ねじの頭を耳の表面より沈め、コネクターの配線余白へ出さない構造です。なべ頭・六角穴付きの円筒頭などへの置き換えはできません。これは蓋・基板押さえ用の樹脂用2mmねじとは別です。ドック内へ沈めるM4ねじ頭は径8mm以下・高さ4mm以下が条件です。金具の実物寸法と穴の収まりは試作で確認してください。

1. ドック裏側の六角穴へM3ナット2個を入れます。
2. ケースを載せる前に、ドックをM4×25とM4ナットでラックに固定します。
3. ケースの底部の耳をドックのM3穴に合わせ、外からM3×12の90度皿ねじで留めます。
4. ケースだけを外す際はM3の2本を外します。配線を外し、ケースを外向きに引き抜けます。

本体ラックの新版側板には、各段の底から高さ60mm、前端（Y=38mm）から62mm／90mmの位置に、M4通し穴を設けます。以前に印刷した側板にはこの穴がないため、新版側板への交換または正確な追加穴加工が必要です。アダプターラックは既存の前柱の穴ピッチ28mmをそのまま使い、旧44×48mmの仮プレートを新ドックへ交換します。ケースは取付耳付きの新版が必要です。

ドックはケース接触側の広い面を下にして造形します。STL出力時にこの方向へ揃えています。生成された1種類のドックを、必要個数分印刷してください。

## 検査と限界

各ラックの4構成、合計8構成で、ケース本体・蓋・独立押さえ・取付ボルト・ナットを配置して干渉を検査します。配線用には各開口の外側に30×20×14mmの設計余白を置き、ラック・ケース・ボルト・ナットすべてに対して検査します。ケースの取り外しには外向き30mmの経路を検査します。コネクターの実測外形・曲げ半径・手指の操作空間を保証する値ではありません。

検査入口は [check_controller_mounts.py](../../../tools/cad/check_controller_mounts.py)。FreeCAD対応Pythonにライブラリパスを設定して実行すると、`build/fan-controller/mount-check-<実行ID>/` に組立FCStd・画像・検査結果・manifestを生成します。macOS既定環境では次のコマンドです。

```sh
PYTHONPATH=/Applications/FreeCAD.app/Contents/Resources/lib /Applications/FreeCAD.app/Contents/Resources/bin/python tools/cad/check_controller_mounts.py
```

実物の取付強度・振動・熱・端子への挿しやすさは未検証です。ケース内部の端子台の逃げとファン／温度センサー開口の修正も別途必要です。まず1組で固定と操作性を確認してください。
