# つまみ穴の位置補正

2026-09-24、青PLAのケース試作について、ユーザーから写真2285と「穴が横に7.62mmずれている」という実測報告を受領。
写真では、つまみを通した蓋が本体より左へずれ、表示窓から端子台が見えている。

- 旧設計の穴中心：基板左端からX=64.17mm。
- 補正方向：穴を左へ7.62mm。
- 補正後の穴中心：X=56.55mm。
- この値は基板端から軸中心を直接測った値ではなく、旧設計と実物の相対差から算出した値。

旧計算は「基板右端から土台左端まで18.09mm」と「土台長12.52mm」を用い、軸が土台中央にあると仮定していた。
算術上は64.17mmになるが、測定対象の解釈を含めた位置推定が実物と一致していないため、軸Xの計算から切り離した。

今回変更するのはつまみ穴のX座標のみ。表示窓と軸Yの適合は、蓋の外周・固定穴を本体に合わせた状態で別途確認する。
CADの形状検査と、補正後の実物適合確認は別であり、後者は未完了。

## 再試作後の追加補正

ユーザーから「だいぶよくなったけど、まだ問題がある。つまみの穴だけさらに2mm左にずらして」と指示を受領。
穴中心Xを56.55mmから54.55mmへ変更する。初回設計64.17mmからの累計移動量は左へ9.62mm。
穴径・Y座標・表示窓・固定穴・ケース本体の寸法は変更しない。今回の補正後の実物適合は未確認。
