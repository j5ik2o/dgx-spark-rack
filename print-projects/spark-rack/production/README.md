# 本番用印刷設定

本番用3MFはまだありません。素材は黒の炭素繊維入り耐熱ナイロン PAHT-CFに決定済みですが、本番の印刷条件は未設定です。条件を決定し、`print-projects/profiles/production/spark-rack.json` を設定してから生成します。[設定方法](../../../docs/タスクランナー.md)を参照してください。

本体を骨格にする案の[肉厚と部品別の造形方向](../../../models/spark-rack/docs/肉厚と造形方向.md)は検討段階です。支持材や印刷経路の検証済み設定ではなく、試作用設定を本番へ代用しません。
