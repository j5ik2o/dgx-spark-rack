# 試作用印刷設定

PLAで仮組みするための3MFです。本番用ではありません。`mise run 3mf:prototype:fan-controller` で `generated/<実行ID>/` に生成します。採用した手調整済み3MFはこのフォルダへ別名保存します。[操作手順](../../../docs/タスクランナー.md)を参照してください。

`fan-controller-blue-pla-body-lid-20260923.3mf` は初回試作の記録です。端子開口の不一致と蓋の薄板押さえの破損が見つかった旧形状のため、現行設計の印刷には使いません。独立したねじ留め押さえを持つ新版は正本から再生成してください。
